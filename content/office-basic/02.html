02차시

받은 업무 파일, 어디서 왜 열릴까

파일이 들어오는 길과 저장되는 곳을 알고, 파일 이름 끝의 꼬리표(확장자)를 읽어 "왜 이 프로그램으로 열리는지" 설명합니다. 안 열릴 때 스스로 해결하는 것까지가 오늘의 끝입니다.

업무 흐름 — 받기·열기PC 카카오톡 · 파일 탐색기

진행 순서

순서진행 과정내용비고
1도입복습, 오늘은 5단계 중 "받기·열기"
2받기 준비PC 카카오톡 설치·로그인, 팀장님 단톡방 들어가기따라하기 — 가장 오래 걸림
3받기 이론파일이 들어오는 3가지 길(카톡, 이메일 첨부, 웹사이트 다운로드)과 저장 위치이론
4열기 이론꼬리표(확장자)와 기본 앱 — 왜 이 프로그램으로 열리나이론
쉬는 시간
5실습실습 C — 받은 업무 파일 이름표 읽기실습
6안 열릴 때압축 풀기, 한컴오피스 뷰어 설치, 연결 프로그램 바꾸기따라하기
7조절 구간휴대폰 ↔ PC 파일 옮기기아래 참고
8정리위험한 꼬리표(.exe·.apk) 구별, 오늘 정리 퀴즈

자주 받는 파일 정리표 (실습 C 정답표)

꼬리표무슨 파일보통 열리는 곳사무실에서 받는 상황
.hwp .hwpx한글 문서한글 / 한컴오피스 뷰어공문, 기관 양식
.pdf인쇄용 문서엣지·크롬증명서, 고지서, 안내 자료
.docx워드 문서Word외부 업체 서류
.xlsx엑셀 표Excel명단, 비품 대장
.pptx발표 자료PowerPoint회의·교육 자료
.jpg .png사진사진 앱행사 사진, 화면 캡처
.mp4동영상미디어 플레이어교육 영상
.zip파일 묶음윈도우 기본 / 반디집여러 서류를 한 번에 받을 때
.exe .apk설치 파일(프로그램)실행됨모르는 사람이 보낸 것은 절대 열지 않기
🛠 실습 C — 받은 업무 파일 이름표 읽기

순서는 ① 단톡방에서 파일 받기 → ② 꼬리표 보이게 켜기 → ③ 파일마다 열리는 프로그램 표에 적기.
강사가 만든 팀장님 단톡방 하나에서 이어갑니다.

  1. 단톡방의 파일 8개를 받고 "카카오톡 받은 파일" 폴더에서 찾기
  2. 파일 탐색기 보기 → 표시 → 파일 확장명 켜기 (윈도우 10은 보기 탭의 "파일 확장명")
  3. 하나씩 더블클릭하고 어떤 프로그램이 열렸는지 학습지 표에 적기
  4. PDF 파일 우클릭 → 연결 프로그램 → 다른 앱 선택 → 크롬으로 열어보기

확인할 것 — 같은 PDF가 엣지에서도 크롬에서도 열리는 이유를 말할 수 있나요? 파일 내용은 그대로고, 여는 도구만 바뀐 것입니다.

📎 준비물
  • 팀장님이 보낸 업무 파일 · 형식별 1건씩 8개 (.exe는 넣지 않고 이름만 소개)
⏸ 조절 구간 — 휴대폰 ↔ PC 파일 옮기기(카톡 "나와의 채팅"). 느리면 4차시로 넘김
📦 오늘 결과물 — PC 카카오톡, 받은 업무 파일 8개와 꼬리표 표
