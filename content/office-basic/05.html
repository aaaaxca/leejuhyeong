05차시

화상회의 참여와 팀 소통

초대받은 Zoom 회의에 들어가 화면을 공유하고, 팀 대화방(디스코드)에 자료를 올리는 순서를 익힙니다. 8차시 주간회의 발표의 연습 무대입니다.

업무 흐름 — 보고하기Zoom · 디스코드
오늘의 상황

팀장님이 외근 중이셔서 "구매 요청서는 Zoom으로 화면 띄워서 설명해 주고, 팀 디스코드에도 올려 줘요"라고 하십니다.

🛠 실습 H — 팀장님 Zoom 회의 들어가기

순서는 ① 초대 링크 열기 → ② 이름 바꾸고 참가 → ③ 마이크·카메라 점검 → ④ 채팅·손들기 해보기.
강사가 연 반 회의방 하나에서 이어갑니다.

  1. 단톡방의 링크를 눌러 Zoom 앱 설치 또는 열기 — 로그인 없이 "회의 참가"
  2. 이름을 "홍길동(행정실)"처럼 바꾸고 참가
  3. 컴퓨터 오디오로 참가 → 마이크·카메라 켜고 끄기
  4. 채팅으로 인사 남기기, 반응에서 손들기

확인할 것 — 말하지 않을 때 음소거가 되어 있나요? 왼쪽 아래 마이크 아이콘에 빗금이 있으면 음소거 상태입니다.

🛠 실습 I — 팀 디스코드에 자료 올리기

순서는 ① 디스코드 가입 → ② 초대 링크로 팀 서버 들어가기 → ③ 채널에 인사 → ④ 3차시 PDF 올리기.
강사가 만든 팀 서버 하나에서 이어갑니다.

  1. 크롬에서 디스코드 가입 (이메일, 생년월일 입력)
  2. 초대 링크로 서버 들어가기 → 왼쪽 채널 목록 살펴보기
  3. "인사" 채널에 자기소개 한 줄
  4. "제출" 채널에 + 버튼으로 PDF 올리기

확인할 것 — 단톡방과 디스코드의 차이를 말할 수 있나요? 디스코드는 주제별 채널로 나뉘어 자료가 섞이지 않습니다.
