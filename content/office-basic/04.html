04차시

서류 발급과 이메일 제출

정부24에서 서류를 떼어 PDF로 받는 순서와, 업무 메일에 파일을 첨부해 보내는 순서를 익힙니다. 공용 PC에서 개인 서류를 다룬 뒤의 마무리 습관도 함께 몸에 붙입니다.

업무 흐름 — 받기·보내기정부24 · Gmail
오늘의 상황

센터에 낼 서류로 주민등록등본이 필요하고, 어제 만든 구매 요청서는 메일로 제출해야 합니다. 받은편지함에는 수상한 메일도 섞여 들어왔습니다.

진행 순서

순서진행 과정내용비고
1도입복습, 오늘은 5단계 중 "받기·보내기"
2인증 이론본인 인증 3가지 — 공동인증서(예전 공인인증서, 파일로 저장), 금융인증서(클라우드 저장), 간편인증(카카오·네이버·PASS 등)이론
3실습실습 F — 정부24에서 주민등록등본 떼어보기실습
4마무리 습관공용 PC 마무리 — 파일 삭제, 휴지통 비우기, 로그아웃따라하기
쉬는 시간
5메일 이론업무 메일의 구조 — 받는 사람, 참조, 제목, 본문, 첨부 / 제목 쓰는 법이론
6실습실습 G — 비품 구매 요청서 메일로 제출실습
7사기 구별진짜·가짜 메일과 문자 구별하기 (예시 6개)이론 + 학습지
8조절 구간첨부파일 내려받기 / 나와의 채팅아래 참고
9정리오늘 정리 퀴즈, 다음 차시 예고
🛠 실습 F — 정부24에서 주민등록등본 떼어보기

순서는 ① 북마크로 들어가 주소 확인 → ② 간편인증 로그인 → ③ 등본 발급 → ④ PDF로 저장 → ⑤ 삭제·로그아웃.

  1. 1차시 "업무" 북마크로 들어가 주소가 gov.kr로 끝나는지 확인
  2. 간편인증으로 로그인 — 공동인증서와 달리 학원 PC에 파일이 남지 않음
  3. 주민등록등본 발급 신청, 주민등록번호 뒷자리는 표시하지 않음으로 선택
  4. 출력 → 프린터 목록에서 "PDF로 저장" 선택
  5. 저장한 PDF 확인 후 삭제 → 휴지통 비우기 → 정부24 로그아웃

확인할 것 — 공용 PC에서 개인 서류를 다룬 뒤 해야 할 세 가지를 말할 수 있나요? 개인정보가 꺼려지는 분은 강사 시연을 보고 집에서 해보기로 선택할 수 있습니다.

🛠 실습 G — 비품 구매 요청서 메일로 제출하기

순서는 ① 새 메일 쓰기 → ② 받는 사람·제목·본문 채우기 → ③ PDF 첨부 → ④ 보내고 보낸편지함 확인.

  1. 1차시에 로그인한 구글 계정으로 Gmail 열기
  2. 받는 사람: 강사(팀장님 역할) 메일 / 제목: "[비품 요청] A4 용지·볼펜 구매 요청드립니다"
  3. 본문 3줄 — 인사, 요청 내용과 총액, 첨부 안내
  4. 클립 모양을 눌러 PDF 첨부 → 보내기 → 보낸편지함에서 첨부 확인

확인할 것 — 첨부한 파일이 .hwp가 아니라 .pdf인가요? 등본처럼 개인 서류는 이 실습에서 보내지 않습니다.
