03차시

업무 파일 정리와 문서 수정

받은 파일을 "나중에 다시 찾을 수 있게" 정리하고, 원본을 지키면서 한글 양식을 고쳐 PDF로 만드는 업무 순서를 익힙니다.

업무 흐름 — 정리하기파일 탐색기 · 한글
오늘의 상황

받은 파일이 폴더에 뒤죽박죽 쌓였습니다. 팀장님이 "비품 구매 요청서 양식 채워서 PDF로 만들어 줘요. 양식 원본은 다음에도 써야 하니까 그대로 두고요"라고 하십니다.

🛠 실습 D — 업무 폴더 만들고 받은 파일 정리하기

순서는 ① 문서 폴더에 "업무" 폴더 만들기 → ② 안에 "공문", "사진", "자료" 폴더 만들기 → ③ 실습 C 파일 옮기고 이름 바꾸기.

  1. 문서 폴더에서 우클릭 → 새로 만들기 → 폴더
  2. 파일을 꼬리표에 맞는 폴더로 끌어다 옮기기 (복사가 아니라 이동)
  3. 파일 이름을 "날짜_내용" 규칙으로 바꾸기 (F2 키)

확인할 것 — 복사와 이동의 차이를 말할 수 있나요? 복사하면 같은 파일이 두 곳에 생겨 어느 쪽이 최신인지 헷갈립니다.

📎 준비물
  • 실습 C의 업무 파일 8개 · 카카오톡 받은 파일 폴더
🛠 실습 E — 한글 양식 고쳐서 PDF로 만들기

순서는 ① 양식 열기 → ② 다른 이름으로 저장 → ③ 칸 채우기 → ④ PDF로 저장.

  1. "공문" 폴더의 양식을 열고, 고치기 전에 먼저 "다른 이름으로 저장" (예: 20261116_비품요청_이름)
  2. 1차시 실습 B에서 비교한 품목·수량·금액을 표 칸에 채우기
  3. 파일 → PDF로 저장하기 (또는 인쇄 → Microsoft Print to PDF)
  4. 원본 양식이 빈 칸 그대로인지 확인

확인할 것 — 같은 이름의 .hwp와 .pdf가 둘 다 생겼나요? 고칠 원본은 .hwp, 보낼 파일은 .pdf입니다. 이 PDF를 4차시에 메일로 보냅니다.
