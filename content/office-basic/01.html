업무용 크롬 세팅

컴퓨터로 일을 시작할 때 막히는 지점을 먼저 짚고, 내 자리 컴퓨터와 익숙해진 뒤 사무 일의 전체 흐름을 이해합니다.

업무 흐름 — 전체 그림윈도우 · 크롬
오늘의 상황

첫 출근날, 행정실 내 자리에 컴퓨터가 놓여 있습니다. 팀장님이 "업무 사이트는 즐겨찾기 해 두고, A4 용지랑 볼펜 가격 좀 알아봐 줘요"라고 하십니다. 오늘은 내 자리 컴퓨터와 친해지고 첫 심부름을 해냅니다.

도입 — 자주 막히는 문제 (짧게만, 자세한 건 해당 차시에서)

막히는 문제다루는 차시

🛠 실습 0 — 컴퓨터 켜고 내 윈도우 확인하기

순서는 ① 켜고 로그인 → ② 화면 구성 찾기 → ③ 윈도우 버전 확인 → ④ 업데이트 확인 → ⑤ 설정 둘러보기.

  1. 전원 버튼 → 잠금 화면에서 아무 키 → 비밀번호(PIN) 입력해 로그인
  2. 바탕화면, 작업표시줄, 시작 버튼, 오른쪽 아래 시계·소리·인터넷 아이콘 하나씩 짚기
  3. 시작 → 설정 → 시스템 → 정보에서 윈도우 10인지 11인지 학습지에 적기
  4. 설정 → Windows 업데이트(윈도우 10은 업데이트 및 보안)에서 "최신 상태"인지 적기 — 학원 PC에서는 설치 버튼을 누르지 않음
  5. 설정 → 시스템 → 디스플레이에서 배율 확인, 소리·인터넷 상태 보기
  6. 시작 → 전원에서 시스템 종료·다시 시작·절전의 차이 알아보기

확인할 것 — 집 컴퓨터에서도 같은 순서로 버전과 업데이트를 확인할 수 있나요?

📎 준비물
  • 내 컴퓨터 확인 학습지 · 빈칸 4개 (윈도우 버전, 업데이트 상태, 화면 배율, 끄는 방법)
🛠 실습 A — 업무 사이트 북마크 폴더 만들기

순서는 ① 사이트 열기 → ② 북마크에 추가 → ③ "업무" 폴더로 묶기.

  1. 사이트 5곳을 각각 새 탭으로 열기
  2. 주소창 오른쪽 별 모양을 눌러 북마크 추가
  3. 북마크바에 "업무" 폴더를 만들고 5곳을 옮기기

확인할 것 — 크롬을 껐다 켜도 "업무" 폴더에서 정부24를 한 번에 열 수 있나요? 4차시에 이 북마크로 들어갑니다.

📎 준비물
  • 업무 사이트 목록 학습지 · 5곳 (정부24, 메일, 학원 홈페이지, 사무용품 쇼핑몰, 지도)
🛠 실습 B — 사무용품 가격 비교해 구매 요청 메모 쓰기

순서는 ① 같은 물건 3곳 검색 → ② 가격·배송비 비교 → ③ 메모장에 구매 요청 정리.

  1. 검색어를 바꿔가며 같은 제품 찾기 (예: "A4 용지" → "A4 복사용지 80g 2500매")
  2. 쇼핑몰 3곳의 상품가·배송비를 학습지 표에 적기 — 결제는 하지 않음
  3. 가장 저렴한 곳과 링크를 메모장에 정리해 저장

확인할 것 — 배송비까지 더해서 비교했나요? 사무실 구매 요청은 "총액"으로 보고합니다.

📎 준비물
  • 팀장님 요청 메시지 · "A4 용지 2박스, 볼펜 1다스 가격 알아봐 주세요"
⏸ 조절 구간 — 크롬 번역으로 외국어 페이지 읽기 / 확대·축소(Ctrl + 마우스 휠). 느리면 생략, 실습 B가 늦어지면 2차시 도입으로 넘김
