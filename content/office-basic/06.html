06차시

엑셀로 업무 대장 만들기

비품 관리 대장을 직접 만들고 금액·합계를 계산해, 한 장짜리 보고용 PDF로 내보내는 순서를 익힙니다. 이 결과가 7차시 보고 자료의 재료가 됩니다.

업무 흐름 — 만들기엑셀 (없으면 구글 시트)
오늘의 상황

비품 관리 대장이 종이로만 있어서 매번 손으로 계산합니다. 팀장님이 "엑셀로 대장 만들어서 합계 내고, 한 장으로 뽑아 줘요"라고 하십니다.

진행 순서

순서진행 과정내용비고
1도입복습, 오늘은 5단계 중 "만들기"
2엑셀 이론엑셀의 구조 — 칸(셀), 가로줄(행), 세로줄(열), 칸 이름(A1) / 엑셀이 "계산하는 표"인 이유이론
3실습실습 J — 비품 관리 대장 만들기실습
4보기 좋게칸 너비 맞추기, 테두리, 머리글 굵게따라하기
쉬는 시간
5정렬·필터원하는 것만 골라 보기이론 + 따라하기
6실습실습 K — 정렬·그래프 넣고 한 장 PDF로실습
7조절 구간필터 / 틀 고정아래 참고
8정리오늘 정리 퀴즈, 다음 차시 예고
🛠 실습 J — 비품 관리 대장 만들기

순서는 ① 머리글 입력 → ② 품목 10개 채우기 → ③ 금액 수식 넣기 → ④ 맨 아래 합계.

  1. 1행에 머리글: 품목 / 수량 / 단가 / 금액 / 비고
  2. 비품 목록의 10개 품목을 옮겨 적기 (복사·붙여넣기)
  3. 금액 칸에 =B2*C2 입력 → 칸 오른쪽 아래 점을 끌어 아래로 채우기
  4. 금액 맨 아래 칸에서 자동 합계(Σ) → "업무 > 자료" 폴더에 "날짜_비품대장"으로 저장

확인할 것 — 수량 하나를 바꾸면 금액과 합계가 같이 바뀌나요? 엑셀이 다시 계산하는 것이 그냥 표와 "계산하는 표"의 차이입니다.

📎 준비물
  • 비품목록.xlsx · 품목 10개 (품목·수량·단가)
🛠 실습 K — 정렬·그래프 넣고 한 장 PDF로 내보내기

순서는 ① 금액 큰 순 정렬 → ② 막대 그래프 넣기 → ③ 인쇄 미리보기로 한 장 맞추기 → ④ PDF로 저장.
실습 J와 같은 파일에서 이어갑니다.

  1. 금액 열을 누르고 데이터 → 내림차순 정렬
  2. 품목과 금액을 선택 → 삽입 → 막대 그래프
  3. 파일 → 인쇄 → "한 페이지에 시트 맞추기" 선택
  4. 프린터를 "Microsoft Print to PDF"로 골라 저장

확인할 것 — PDF 한 장에 표와 그래프가 다 들어가 있나요? 이 그래프를 7차시 보고 자료에 넣습니다.

📎 준비물
