트렌드 팔로워 팀 — 매주 저절로 오는 SNS 트렌드 브리핑

수집·선별·해설·편집으로 역할을 나눈 에이전트 팀을 만들어, 매주 같은 기준의 SNS 트렌드 브리핑을 받습니다.

이론 40 · 실습 80Claude 유료 + Code 탭

이론

  • 팀은 결과를 좋게 하는 장치가 아니라 같은 결과를 반복해서 얻는 장치
  • 팀원 카드 5요소 — 특히 '언제 부르나'와 '하지 말 것'
  • 링크 칸을 끝까지 끌고 가면 지어낸 기사가 낄 자리가 없다
  • 예약 작업: 재료가 웹에 있어서 트렌드 팀은 예약에 잘 맞는다 (유료 기능)
🛠 실습 A — 문장 하나로 팀 만들어 보기

순서는 ① 한 문장 던지기 → ② 바로 돌려보기 → ③ 다섯 군데(링크·날짜·선별 근거·시사점·내 취향) 훑기.
Code 탭 새 대화에서 시작합니다.

📎 준비물
  • 빈 폴더 트렌드팀_A · Code 탭 작업 폴더
🛠 실습 B — 관심사 프로필로 4인 팀 설계하고 돌리기

순서는 ① 관심사 프로필(SNS 마케팅 키워드·관심 없는 것 3개) → ② 팀원 4명 만들기 → ③ 한 명씩 검증 → ④ 통째로 돌리기 → ⑤ 예약 걸기(시연).
새 폴더 · 새 대화에서 시작해 한 대화에서 이어갑니다.
