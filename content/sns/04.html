04차시

브랜드 규칙과 비주얼 — 매번 같은 느낌 내기

색·글꼴·말투·금지 표현을 한 장의 규칙으로 고정하고, 그 규칙으로 무드보드와 프로필 이미지를 만듭니다.

이론 35 · 실습 85Claude Pro + 이미지 생성 도구

이론

  • 왜 규칙을 파일로 고정하나 — 대화로만 시키면 다음 주엔 색과 말투가 달라진다
  • 규칙 한 장의 칸: 색(HEX 코드) · 글꼴 · 말투 · 구성 · 금지 표현 · 숫자는 자료에 있는 것만
  • 이미지 프롬프트 = 브랜드 규칙을 그림 언어로 바꾼 것 (분위기·빛·구도·색)
  • 저작권: 사진·글꼴이 상업용으로 써도 되는지는 사람이 확인
🛠 실습 A — 브랜드 규칙 한 장 만들기

순서는 ① 브랜드 한 장에서 규칙 뽑기 → ② 금지 표현 5개 정하기 → ③ Project 지식에 저장.
브랜드 스튜디오 Project 안 새 대화에서 시작합니다.

📎 준비물
  • 브랜드 한 장 · Project 지식에 있음
🛠 실습 B — 무드보드와 프로필 이미지

순서는 ① Claude에게 이미지 프롬프트 3개 받기 → ② 이미지 생성 도구에 넣기 → ③ 규칙과 맞는지 고르기.
실습 A와 같은 대화에서 이어갑니다.
