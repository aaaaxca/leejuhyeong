02차시

Project로 브랜드 만들기 — 브랜드 인터뷰

Project 지침에 인터뷰 규칙을 넣고, AI와 문답하며 브랜드를 '한 장'으로 정리합니다. 이 한 장이 10일 내내 쓰입니다.

이론 35 · 실습 85Claude Pro

이론

  • Project = 지침(매번 지킬 규칙) + 지식(매번 참고할 자료)
  • "홈페이지·SNS 만들어줘"만 하면 빈 껍데기가 나오는 이유
  • 물어볼 7가지: 이름·한 줄 소개 / 누구를 위한 / 무엇을 / 왜 / 분위기 / 바라는 행동 / 자주 받을 질문
  • "내가 말하지 않은 사실은 지어내지 않는다" — 없는 정보는 [준비 중]
🛠 실습 A — '브랜드 스튜디오' Project 만들기

순서는 ① Project 만들기 → ② 인터뷰 지침 붙여넣기 → ③ 지침이 지켜지는지 한 번 물어보기.
Project 안 새 대화에서 확인합니다.

📎 준비물
  • 브랜드 인터뷰 지침 · 페이지에 있음 (12차시 실습 B ① 지침을 SNS용으로 수정)
🛠 실습 B — 인터뷰로 '브랜드 한 장' 만들기

순서는 ① 인터뷰 시작 → ② 7가지 답하기 → ③ 브랜드 한 장 받아 고치기 → ④ Project 지식에 저장.
Project 안 새 대화에서 시작합니다. 반이 함께 정할 칸(2·4·7번)은 다 같이 정합니다.

📎 준비물
  • 데이로그 예시 답변표 · 페이지에 있음 · 7문항
