05차시

콘텐츠 기획 — 기둥과 4주 캘린더

무엇을 반복해서 올릴지(콘텐츠 기둥)를 정하고, 4주 캘린더를 아티팩트 도구로 만들어 첫 주 캡션까지 씁니다.

이론 35 · 실습 85Claude Pro

이론

  • 콘텐츠 기둥 3~4개 — 매번 새 아이디어 대신 정해진 줄기에서 꺼낸다
  • 포맷 고르기: 카드뉴스(캐러셀) · 릴스 · 스토리 — 무엇을 어디에
  • 아티팩트는 답이 아니라 물건 — 캘린더를 '도구'로 받으면 계속 고쳐 쓴다
  • 만드는 순서: 뼈대 → 하나씩 → 확인 (한 번에 다 만들지 않기)
🛠 실습 A — 콘텐츠 기둥과 4주 캘린더 도구

순서는 ① 기둥 3~4개 정하기 → ② 캘린더 뼈대(날짜·기둥·포맷) → ③ 필터 붙이기 → ④ 한 주에 기둥이 고르게 섞였는지 확인.
브랜드 스튜디오 Project 안 새 대화에서 시작합니다.

📎 준비물
  • 브랜드 한 장 · 페르소나 · 타깃 질문 10개 · Project 지식에 있음
🛠 실습 B — 1주차 게시물 3개 캡션·해시태그

순서는 ① 캡션 초안 → ② 브랜드 규칙으로 검토(금지 표현·지어낸 숫자) → ③ 해시태그.
실습 A와 같은 대화에서 이어갑니다.

📎 준비물
  • 실습 A의 4주 캘린더 · 같은 대화에 있음
  • 브랜드 규칙 · Project 지식에 있음
📦 오늘 결과물 — 4주 콘텐츠 캘린더(아티팩트), 1주차 캡션 3개
숙제 — 실습용 인스타그램을 프로페셔널(크리에이터·비즈니스) 계정으로 전환해 오기 (10차시에 필요)
