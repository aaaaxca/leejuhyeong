03차시

시장·타깃 조사 — 출처 있는 조사만 믿기

비슷한 쥬얼리 브랜드와 타깃을 조사하되, 출처를 확인하고 그럴듯한 가짜를 걸러 내는 습관을 만듭니다.

이론 40 · 실습 80Claude Pro (웹 검색 켜기)

이론

  • 그럴듯함 ≠ 정확함 — 출처 링크·날짜가 없는 내용은 쓰지 않는다
  • 자료 사각지대: AI는 로그인해야 보이는 인스타 내용을 읽지 못한다 → 공개 웹 + 내가 찍은 화면 캡처로 보완
  • 페르소나: "20~30대 여성"이 아니라 어떤 상황에서 무엇을 찾는 사람인지
🛠 실습 A — 비슷한 쥬얼리 브랜드 3곳 비교표

순서는 ① 후보 찾기 → ② 출처 링크로 확인 → ③ 비교표(톤·주 콘텐츠·차별점) → ④ 데이로그가 비워 둔 자리 찾기.
브랜드 스튜디오 Project 안 새 대화에서 시작합니다.

📎 준비물
  • 참고 계정 화면 캡처 · 이미지 · 각자 2~3장 (프로필·인기 게시물) · 예: 논논(NONENON) 같은 감성 쥬얼리 브랜드
  • 브랜드 한 장 · Project 지식에 있음
🛠 실습 B — 타깃 페르소나 2명과 그들이 묻는 질문 10개

순서는 ① 페르소나 2명 → ② 실제로 검색·질문할 문장 10개 → ③ Project 지식에 저장.
실습 A와 같은 대화에서 이어갑니다.

📎 준비물
  • 실습 A의 비교표 · 같은 대화에 있음
