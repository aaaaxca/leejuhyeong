카드뉴스 만들기 — HTML로 디자인하고 PNG로 저장

브랜드 규칙을 CLAUDE.md에 넣어 톤을 고정하고, 카드뉴스 5장을 만들어 인스타 크기 PNG로 저장합니다.

이론 30 · 실습 90Claude Pro + 데스크톱 앱(Code 탭)

이론

  • Code 탭이 하는 일 — 내 폴더 안에서 파일을 만들고 고치는 Claude (필요한 만큼만 설명)
  • 왜 HTML로 만드나: 말로 고치기 쉽고 디자인이 파일로 남는다 → 사진처럼 찍어 PNG로
  • 인스타 세로형 1080×1350(4:5), 캐러셀은 최대 20장 — 오늘은 5장(표지 1 · 내용 3 · 마무리 1)
  • 결과가 이상하면 결과를 손으로 고치지 말고 규칙을 고친다
🛠 실습 A — 브랜드 규칙을 CLAUDE.md로 옮기기

순서는 ① 작업 폴더 고르기 → ② 브랜드 규칙 저장 → ③ 규칙을 읽었는지 확인.
