07차시

숏폼 영상 기획 — 트렌드에서 대본·장면까지

릴스·쇼츠 한 편을 AI와 순서대로 기획합니다. 어디까지 AI에게 맡기고 어디서 사람이 고르는지 구분합니다.

이론 30 · 시연 15 · 실습 75Claude Pro (+ 영상 생성 도구는 시연)

이론

  • 영상은 완전 순차 작업 — 대본 없이 장면을 못 만든다 → 팀이 아니라 지시서 한 장 + 한 명
  • 흐름: 벤치마킹 → 주제 고르기(사람) → 대본 → 장면별 프롬프트 → 생성(사람+도구) → 편집·업로드(사람)
  • 참고 채널은 문체만 배우고 내용은 새로 — 대본 베끼기 금지
  • 반복되는 조사는 에이전트 팀에게 — 수집·선별로 역할을 나누면 매주 같은 기준의 트렌드 브리핑이 온다 (강사 시연)
  • 첫 3초 훅, 자막을 전제로 한 짧은 문장
🛠 실습 A — 벤치마킹으로 아이디어 10개

순서는 ① 강사 시연 — 트렌드 팀(수집·선별 2명)이 정리한 이번 주 쥬얼리 릴스 트렌드 보기 → ② 참고 채널 인기 영상 목록 캡처 붙이기 → ③ 제목·첫 장면 패턴 분석 → ④ 데이로그용 아이디어 10개 → ⑤ 반이 하나 고르기.
브랜드 스튜디오 Project 안 새 대화에서 시작합니다.

📎 준비물
  • 참고 채널 인기 영상 목록 캡처 · 이미지 · 1~2장
  • 트렌드 브리핑 · 강사 시연 결과 · 페이지에 있음
🛠 실습 B — 30초 릴스 대본과 장면별 프롬프트

순서는 ① 대본(훅 3초 포함) → ② 스스로 채점하고 고쳐 쓰기 → ③ 장면별 이미지·영상 프롬프트 → ④ 자막 문구.
실습 A와 같은 대화에서 이어갑니다.

📎 준비물
  • 실습 A에서 고른 아이디어 · 같은 대화에 있음
  • 브랜드 규칙 · Project 지식에 있음
⏸ 조절 구간 — 빠른 수강생은 강사가 보여 준 트렌드 팀 카드를 받아 내 관심사로 한 번 돌려 보기 (Code 탭)
📦 오늘 결과물 — 릴스 대본 1편, 장면별 프롬프트, 자막 문구 (생성·편집은 강사 시연 또는 과제)
