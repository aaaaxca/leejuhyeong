2차시에는 내 사진을 바꿔 봤다면, 오늘은 이미지를 처음부터 만들고 원하는 부분만 고칩니다. 3차시 카드뉴스 문구를 그림으로 만들어 보고, 잘 만든 제품 포스터를 분석해 비슷한 포스터를 만들고, 가게 로고를 기획해 만들고 다듬은 뒤, 마지막에는 로고 기획안을 문서로 정리해 Word로 내려받습니다.

1글이 그림이 되는 순간 — 3차시 카드뉴스를 이미지로

2차시에서는 내 사진을 다른 그림체로 바꾸는 것을 해 봤습니다. 오늘은 ChatGPT로 이미지를 처음부터 만듭니다. 먼저 3차시에 만든 카드뉴스 문구를 그대로 그림으로 만들어 보고, 무엇이 아쉬운지 확인합니다.

ChatGPT에서 이미지를 만드는 방법은 두 가지입니다. 입력창의 + 버튼 → 이미지 만들기를 고른 뒤 설명하거나, 대화하듯 "~한 이미지를 만들어줘"라고 쓰면 됩니다. ChatGPT 이미지는 그림 속 글자를 비교적 정확하게 넣는 편이라 카드뉴스·포스터·로고처럼 글자가 들어가는 이미지에 잘 맞습니다.

실습 A — 카드뉴스 문구로 일단 만들어 보기
  1. 문구 준비 — 3차시 실습 C에서 받은 카드 6장 문구를 가져옵니다. 3차시 대화가 남아 있으면 거기서 이어서 하고, 없으면 새 채팅에 문구를 붙여 넣고 시작합니다.
    3차시 문구가 없다면 — 예시 문구 펼치기
    예시 — 골목분식 '치즈 떡볶이' 카드뉴스 문구
    [카드뉴스 문구]
표지 | 치즈가 쭉, 골목분식 치즈 떡볶이 | 새로 나온 신메뉴를 소개합니다
2장 | 매콤함 위에 고소함 한 겹 | 매콤한 떡볶이 위에 모차렐라 치즈를 듬뿍
3장 | 쫀득한 떡, 길게 늘어나는 치즈 | 한 입마다 쭉 늘어나는 즐거움
4장 | 점심 한 끼로 든든하게 | 바쁜 직장인 점심에 딱 맞는 양
5장 | 매운 게 걱정이라면 | 치즈가 매운맛을 부드럽게 잡아 줍니다
마무리 | 오늘 점심은 골목분식에서 | 따끈할 때 먹으러 오세요
  2. 표지 만들기 — 일부러 짧게 시켜 봅니다 
    위 카드뉴스 문구 중 표지를 인스타그램 카드 이미지로 만들어줘. 제목은 문구 그대로 정확히 넣어줘.
  3. 2장 이어서 만들기 — 같은 대화에서 실행 
    방금 만든 표지와 같은 분위기로 2장을 만들어줘. 제목은 문구 그대로 정확히 넣어줘.
    한글이 문구와 다르게 나왔다면, 같은 대화에서 "2장의 제목 글자만 위 문구와 똑같이 고쳐줘. 나머지는 그대로 둬."처럼 글자만 말로 고쳐 달라고 합니다.
  4. 결과 보기 — 짧게 시켰는데도 그럴듯하게 나왔을 겁니다. 그런데 표지와 2장이 거의 같은 그림으로 나오지 않았나요? "같은 분위기로"라고만 하면 AI는 그림체·색뿐 아니라 구도와 장면까지 그대로 유지합니다. 무엇을 유지하고 무엇을 바꿀지 말하지 않았기 때문입니다. 그림체·색·글꼴은 유지하고 장면·구도는 바꾸라고 칸을 나눠 말해야 하는데, 그 칸을 2번 섹션에서 배웁니다.
여유가 있으면
  1. 나머지 카드 이어서 — 같은 대화에서 3장부터 마무리까지 한 장씩 
    방금 만든 카드와 같은 분위기로 3장을 만들어줘. 제목은 문구 그대로 정확히 넣어줘.
    "3장"만 4장, 5장, 마무리로 바꿔 가며 실행합니다.
  2. 마음에 드는 카드 다운로드 — 2번 섹션에서 배운 뒤 다시 만들어 비교해 봐도 좋습니다.

6장을 한 번에 만들라고 하면 카드마다 분위기가 달라지고 글자도 틀리기 쉽습니다. 한 장씩 만들고, 글자는 꼭 문구와 비교하세요.

2레퍼런스에서 배우기 — 제품 포스터 분석과 제작

ChatGPT는 이미지를 보고 이해할 수도 있습니다. 사진, 스크린샷, 포스터를 올리고 질문하면 내용을 읽고 해석해 줍니다. 잘 만든 예를 분석해 두면, 내가 원하는 것을 말로 설명하기가 훨씬 쉬워집니다.

실습 C — 다섯 칸으로 제품 포스터 만들기
  1. 이미지 만들기 켜기 — 새 채팅을 열고 입력창의 + 버튼 → 이미지 만들기를 선택합니다. 실습 A에서는 대화하듯 시켰다면, 이번에는 이미지 만들기 기능을 켜고 시작합니다.
  2. 예시 제품으로 실행하기 — 실습 B의 02에서 받은 프롬프트의 다섯 칸 틀은 그대로 두고, 내용만 콜드브루 커피로 채운 프롬프트입니다. 복사해 입력창에 붙여 넣고 실행한 뒤, 실습 B의 포스터와 비교해 보세요.
    예시 — 다섯 칸을 콜드브루 커피로 채운 프롬프트
    세로 2:3 비율의 프리미엄 콜드브루 커피 브랜드 광고 포스터를 제작해줘.

대상: 중앙 하단에 진한 갈색 커피가 담긴 투명한 유리병과 무광 검은색 캡을 배치하고, 주변에는 얼음 몇 조각, 흩어진 원두, 짙은 회색 자연석을 배치해줘.

스타일: 미니멀한 에디토리얼 광고 스타일로, 실제 스튜디오에서 촬영한 듯한 사실적인 제품 사진과 세련된 매거진 디자인을 표현해줘. 유리병에 맺힌 물방울과 원두의 질감이 섬세하게 드러나도록 해줘.

색: 밝은 회색과 오프화이트를 배경으로 사용하고, 짙은 커피 브라운과 차가운 하늘색을 포인트 컬러로 활용해줘. 시원한 아침 자연광과 또렷한 그림자로 깔끔하고 상쾌한 분위기를 만들어줘.

구도: 제품을 중앙 하단에 크게 배치하고, 왼쪽 상단에는 넓은 타이포그래피 영역을 확보해줘. 오른쪽에는 얼음과 원두가 자연스럽게 흩어지도록 배치하고, 여백을 충분히 활용해 균형 잡힌 비대칭 레이아웃을 구성해줘.

글자: 왼쪽 상단에 크고 굵은 검은색 산세리프 글꼴로 'COLD BREW COFFEE'를 세 줄로 배치해줘. 제목 아래에는 작고 간결한 글씨로 'SLOW. SMOOTH. FRESH.'를 추가해줘. 다른 장식 문구는 최소화하고 제품명이 가장 먼저 눈에 들어오도록 해줘.
    실습 B에서 받은 프롬프트는 사람마다 조금씩 다릅니다. 내 결과의 틀을 쓰되, 칸이 빠져 있다면 위 예시처럼 다섯 칸을 모두 채우세요.
    실행한 뒤 — 원작과 비교해 보기

    제품·색·소품·글자는 다른데도 나란히 놓으면 원작이 떠오릅니다.

    배치가 같습니다 — 왼쪽 위 세 줄 제목과 슬로건, 가운데 아래 받침대 위의 병, 오른쪽 위에서 뻗는 식물까지 구도 칸을 그대로 가져왔기 때문입니다.

    원작만의 장식이 따라옵니다 — 맨 위 가운데 머리글, 왼쪽 세로선과 눈금, 모서리 십자 표시, 구석의 작은 시리즈 문구처럼, 사람들이 "그 포스터 같다"고 느끼는 부분입니다.

    문제가 될 수 있는 부분 — AI로 만들었다고 안전한 것은 아닙니다. 수업 연습으로는 괜찮지만, 원작이 떠오를 만큼 닮은 이미지를 판매·광고에 쓰면 표절 시비나 분쟁이 생길 수 있습니다. 분석은 배우는 데 쓰고, 실제로 쓸 결과물은 구도와 장식을 내 것으로 바꿔야 합니다.

  3. 원작과 달라지게 바꾸기 — 같은 대화에서 대상 · 색 · 글자는 그대로 두고, 배치를 뒤집고 장식을 덜어 내 다시 실행 
    방금 만든 포스터에서 대상, 색, 글자 내용은 그대로 두고 레이아웃만 새로 구성해줘.

구도:
- 제목과 슬로건은 오른쪽 상단으로 옮기고 오른쪽 정렬해줘.
- 오른쪽에 있던 커피나무 가지는 좌우를 반전해 왼쪽 상단에서 뻗어 나오게 해줘.
- 위쪽 가운데 머리글은 왼쪽 상단 모서리로 옮겨줘.
- 구석의 작은 시리즈 문구는 오른쪽 하단 모서리로 옮겨줘.

장식:
- 세로선과 눈금, 십자 표시는 모두 빼고 깨끗한 여백으로 남겨줘.

제품은 지금 위치와 크기를 유지하고, 새 배치에서도 제목이 가장 먼저 눈에 들어오도록 균형을 맞춰줘.
    밋밋하다면 — 나만의 장식 더하기 (같은 대화에서 이어서)
    오른쪽 하단의 작은 시리즈 문구 바로 위에 세로로 긴 바코드를 하나 넣고, 그 위에 가는 세로선 하나를 더해줘.
나머지는 모두 그대로 두고, 바코드와 선은 제목과 같은 검은색으로 얇고 정돈되게 표현해줘.
    팁 — 구도는 제품의 분위기에 맞춰 바꾸면 자연스럽습니다. 시원한 음료라면 얼음 위로 내려다본 구도, 향수처럼 고급스러운 제품이라면 넓은 여백 가운데 제품 하나, 먹거리라면 가까이 다가간 클로즈업처럼 정해 보세요. 바꾼 뒤에는 원작과 나란히 놓고 떠오르는지 다시 확인합니다.
  4. 내 제품으로 바꾸기 — 같은 틀에 내 제품을 넣어 다섯 칸을 다시 채워 실행 (예: 핸드크림, 향수, 텀블러). 구도와 장식은 03처럼 원작과 다르게 정하세요.

칸으로 나눠 두면 바꿀 곳만 골라 고칠 수 있습니다. 스타일·색·구도를 그대로 두면 분위기가 같은 시리즈 포스터가 됩니다.

3처음부터 기획하기 — 가게 로고

이번에는 참고할 이미지 없이 브랜드 기획부터 시작합니다. 무엇을 정해야 하는지부터 AI에게 묻고, 업종·이름·손님·분위기를 대화로 확정한 뒤, 로고의 다섯 칸도 AI와 하나씩 골라 정합니다. 2차시의 틀(#정할 것 · #제약조건 · #출력형식)과 3차시의 역질문·나눠서 시키기를 실제로 쓰는 실습입니다. 포스터와 달리 로고는 단순하게, 색은 적게 정하는 것이 좋고, 만든 뒤에는 전체를 다시 만들지 않고 고칠 곳만 고칩니다.

처음부터 끝까지 같은 대화에서 이어서 진행합니다. 앞에서 준 역할과 정한 내용을 AI가 계속 기억하기 때문입니다.

  1. 무엇을 정해야 하는지 묻기 — 새 채팅에서 시작 
    너는 10년 차 브랜드 디자이너야. 작은 가게의 브랜드와 로고를 처음 만들려고 해.
로고를 만들기 전에 무엇을 먼저 정해야 하는지, 꼭 필요한 것부터 순서대로 알려줘.
각 항목은 한 줄로 설명해줘.
    브랜드를 처음 만들어 보면 무엇부터 정해야 할지 모릅니다. 그럴 땐 바로 시키기보다 먼저 물어봅니다. 답은 사람마다 다르게 나올 수 있습니다.
  2. 범위를 정해 기획하기 — 같은 대화에서 이어서 실행 
    좋아. 로고를 만들기 전에, 브랜드 기획부터 같이 정하자.

#정할 것
업종, 브랜드 이름, 주요 손님, 분위기 — 이 네 가지만 정해줘.

#제약조건
- 질문은 한 번에 하나씩, 모두 합쳐 5개 이내로 해줘.
- 질문마다 고를 수 있는 선택지를 3개씩 같이 보여줘.
- 로고 디자인, 색, 글꼴은 아직 묻지 말고, 이미지도 만들지 마.

#출력형식
네 가지가 정해지면 질문을 멈추고, 이름 / 업종 / 주요 손님 / 분위기 네 줄로 정리해줘.
    #정할 것에는 01의 답에서 오늘 꼭 필요한 것 4가지를 골라 넣습니다. 고르기 어렵다면 위 예시 그대로 쓰세요. 질문 수와 멈출 때를 정해 주지 않으면 AI는 잎 개수 같은 세부까지 끝없이 묻습니다. 브랜드 이름 선택지가 마음에 들지 않으면 "후보 3개를 더 제안해줘"라고 합니다.
    예시 — 정리된 기획

    이름: 모퉁이 (MOTUNGI COFFEE)
    업종: 골목 모퉁이에 있는 작은 동네 카페
    주요 손님: 근처 직장인과 동네 단골
    분위기: 따뜻하고 아늑한, 편하게 들르는 쉼터

다섯 칸 정하기
  1. 스타일 · 색 · 구도 · 글자 고르기 — 같은 대화에서 이어서 실행 
    좋아. 이 기획을 바탕으로 로고의 스타일, 색, 구도, 글자를 하나씩 정하자.

#제약조건
- 한 번에 한 칸씩, 칸마다 선택지 3개를 장단점과 함께 보여줘.
- 색은 색 이름과 색상 코드를 함께 보여줘.
- 질문은 4개로 끝내고, 이미지는 아직 만들지 마.

#출력형식
다 정해지면 대상 · 스타일 · 색 · 구도 · 글자 다섯 칸으로 된 로고 프롬프트로 정리해줘.
    예시 — 완성된 다섯 칸 로고 프롬프트

    동네 작은 카페 '모퉁이'의 로고를 만들어줘.
    스타일: 골목 모퉁이에 있는 커피잔을 표현한 심플한 라인 아이콘, 따뜻하고 아늑한 느낌
    색: 베이지(#E8D5B7)와 짙은 갈색(#5A3825) 두 가지만
    구도: 정사각형, 가운데 정렬, 흰 배경
    글자: 아이콘 아래에 영문 'MOTUNGI COFFEE', 둥근 고딕 느낌

생성
  1. 로고 만들기 — 같은 대화에서 입력창의 + 버튼 → 이미지 만들기를 선택하고, 03에서 받은 프롬프트를 붙여 넣어 실행
부분만 고치기

아래 프롬프트는 '모퉁이' 로고 기준입니다. 내 로고에 맞게 고칠 곳과 내용을 바꿔서 실행하세요.

  1. 마크업 — 만든 로고를 클릭 → 아래 도구 막대의 마크업으로 커피잔을 표시하고 실행 
    이 커피잔 위에 하트 모양 라떼 아트를 넣어줘
  2. 지우기 — 지우기를 고르고, 로고에서 없애고 싶은 부분을 칠해 지우기 예: '모퉁이' 로고라면 가로등
  3. 말로 고치기 — 같은 대화에서 실행 
    나머지는 그대로 두고, 글자 색만 짙은 초록으로 바꿔줘
  4. 배경 제거 후 활용 이미지 만들기 — 배경 제거로 로고만 남긴 뒤 실행 
    이 로고를 그대로 써서, 테이크아웃 컵과 가게 간판에 적용한 모습을 각각 보여줘
  5. 마음에 드는 로고와 활용 이미지를 다운로드해 두기 — 4번 섹션 기획안에 씁니다

한 번에 여러 곳을 고치라고 하면 엉뚱한 곳까지 바뀌기 쉽습니다. 한 번에 하나씩 고치세요.

4문서로 정리하기 — 로고 기획안

오늘 만든 로고를 한 장짜리 기획안으로 정리합니다. ChatGPT에 문서를 부탁하면 답변 안에 글 블록이라는 문서 칸으로 받을 수 있습니다. 대화 속 답변과 달리 문단을 골라 그 부분만 다시 쓰게 할 수 있고, 다 고친 뒤 원하는 파일 형식으로 내려받을 수 있습니다.

실습 E — 글 블록으로 기획안 쓰고 Word로 내려받기
  1. 기획안을 문서로 받기 — 실습 D의 대화에서 이어서 실행 
    지금까지 정한 브랜드와 로고의 기획안을 한 장짜리 글 블록으로 만들어줘.
항목: 브랜드 이름 / 로고 콘셉트 / 색상과 그 이유 / 글꼴 느낌 / 로고 활용 예(컵, 간판, SNS) / 앞으로 만들 것
표와 짧은 설명을 섞어서 정리해줘.
    "문서로 만들어줘"라고만 하면 Word 파일로 바로 만들어 버릴 수 있어서, 파일이 아니라 화면 안의 글 블록으로 달라고 분명히 말합니다. 일반 글로 나오면 "이 기획안을 글 블록으로 다시 보여줘"라고 한 번 더 요청합니다.
  2. 크게 열기 — 문서 칸의 확대 아이콘을 눌러 전체 화면으로 엽니다
  3. 직접 고치기 — 이름, 오타, 짧은 문장처럼 간단한 것은 문서를 클릭해 직접 고칩니다 (예: '디자인 의도' 문장을 내 말로 줄이기)
  4. 수정 요청으로 맡기기 — 직접 하기 번거로운 것만 AI에게 맡깁니다. '앞으로 만들 것' 목록을 드래그해 선택 → 위에 뜨는 수정 요청을 누르고 입력 
    이 목록을 3개월 일정표로 바꿔줘. 월 / 할 일 / 결과물 순서의 표로.
    선택한 부분만 바뀌고 나머지는 그대로 남습니다. 간단한 건 내가, 번거로운 건 AI가 — 이렇게 나눠 쓰면 빠릅니다.
  5. Word로 내려받기 — 문서 칸 위쪽의 다운로드 아이콘 → Microsoft Word를 골라 내려받습니다. 메뉴에서 Word가 안 되거나 Markdown만 받아진다면, 같은 대화에서 파일로 만들어 달라고 합니다. 
    이 글 블록 내용을 표와 구성을 그대로 유지해서 Word 파일로 만들어줘. 만든 로고 이미지도 문서 위쪽에 넣어줘.
    글 블록의 다운로드 메뉴와 AI가 따로 만들어 주는 파일은 다른 기능입니다. 메뉴는 계정·화면에 따라 받을 수 있는 형식이 다를 수 있고, 파일로 요청하면 Word·PDF로 받을 수 있습니다.
  6. 로고 이미지 확인하기 — 내려받은 파일을 Word(또는 한글·구글 문서)로 열어 봅니다. 로고가 들어 있지 않다면 실습 D에서 다운로드한 로고와 활용 이미지를 붙여 넣으면 기획안이 완성됩니다

글 블록의 버튼 이름과 위치는 업데이트로 바뀔 수 있습니다.
