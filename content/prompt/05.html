1Midjourney란 — ChatGPT 이미지와 무엇이 다를까

Midjourney는 글로 쓴 프롬프트를 바탕으로 새 이미지를 만드는 이미지 생성 AI입니다. 대상, 상황, 분위기, 색감, 구도, 그림체를 문장으로 쓰면 AI가 해석해 이미지로 만들어 줍니다. 가입과 결제는 1차시 실습 C에서 이미 했습니다.

디퓨전(Diffusion) 모델

Midjourney 같은 이미지 생성 AI는 대부분 디퓨전 방식으로 그림을 만듭니다. 아무 형태도 없는 노이즈(지지직 화면)에서 시작해, 노이즈를 조금씩 걷어 내며 형태와 세부를 만들어 갑니다. 생성 중에 흐릿한 화면이 점점 선명해지는 모습을 보면 바로 이 과정입니다.

실습 A — 남의 프롬프트를 ChatGPT로 풀어 읽기

영어를 몰라도 괜찮습니다. 잘 만든 이미지의 프롬프트를 ChatGPT에 넣어 한국어로 풀고, 4차시의 다섯 칸(대상 · 스타일 · 색 · 구도 · 글자) 중 무엇이 들어 있고 무엇이 빠졌는지 공부합니다.

  1. 왼쪽 탐색 → 위쪽에서 이미지 목록을 고른 뒤, 마음에 드는 이미지 하나를 클릭합니다 '스타일' 목록을 열면 스타일 코드만 나오고 프롬프트가 없습니다.

  3. ChatGPT에 아래 프롬프트 풀이 키트를 붙여 넣고, 맨 아래에 복사한 프롬프트를 붙여 실행

잘 만든 남의 프롬프트를 풀어 읽는 것이 가장 빠른 공부입니다. 그대로 베껴 쓰는 대신, 어떤 단어가 어떤 효과를 냈는지만 가져오세요.

3첫 이미지 만들기

Midjourney는 영어 프롬프트를 기본으로 합니다. 영어를 몰라도 ChatGPT에 한국어로 주제만 알려 주면 영어 프롬프트를 만들어 줍니다. 아래 키트는 하나의 주제를 세 단계로 키워 줍니다. 프롬프트가 구체적일수록 결과가 어떻게 달라지는지 직접 비교해 보세요.

단계모양예 — 선크림을 소개하는 뷰티 유튜버
1. 단어만주제를 영어 단어 2~3개로뷰티 유튜버, 선크림
2. 색과 그림체를 더한 문장색 하나와 그림체 하나를 넣은 한 문장+ 연분홍 튜브(색), 3D 패션 인형 스타일(그림체)
3. 단어를 쉼표로 나열분위기 · 조명 · 구도 단어를 더해 쉼표로+ 밝고 친근한 분위기, 부드러운 스튜디오 조명, 허리 위 구도

  4. 세 결과를 비교합니다 — 1단계는 그림체를 말하지 않아서 4장이 사진, 그림 등 제각각으로 나올 수 있고, 2단계에서 색과 그림체가 정해지고, 3단계에서 4장이 비슷한 구도로 모입니다 제품 라벨에 알 수 없는 영어 글자가 생길 수 있습니다. 1섹션 표처럼 Midjourney는 그림 속 글자에 약합니다.
  5. 한 칸만 바꿔 보기 — ChatGPT에 이어서 요청하고 다시 실행
    키트 3 · 한 칸만 바꾸기
    3단계 프롬프트에서 그림체만 실사 사진으로 바꿔줘. 나머지는 그대로 두고, 바뀐 부분을 한국어로 알려줘.
    같은 유튜버가 인형에서 실제 사람처럼 바뀌는지 3단계 결과와 비교해 보세요. 다른 칸도 '제품만 민트색 핸드크림으로', '조명만 창가 햇살로', '구도만 얼굴 클로즈업으로'처럼 바꾸고 싶은 칸과 내용만 한국어로 쓰면 됩니다.

2차시의 "말하지 않은 부분은 AI가 흔한 쪽으로 채운다"가 Midjourney에서도 그대로입니다. 오늘 만든 세 가지 키트는 6~9차시에서도 계속 씁니다.

내가 원하는 특정 제품으로 고정할 수 있을까?

어느 정도는 됩니다. 제품 사진을 참조 이미지로 넣으면 튜브 모양, 색 같은 큰 형태는 잘 따라옵니다(8차시). 하지만 라벨 글자와 로고는 대부분 뭉개지거나 바뀌어서 "그 제품 그대로"는 어렵습니다.

정확히 그 제품이어야 한다면 편집기에서 실제 제품 사진을 레이어로 얹거나(9차시), 라벨 글자를 더 잘 살리는 ChatGPT 이미지(4차시)를 쓰거나, 사람만 만들고 제품은 실제 사진으로 합성합니다. 다른 회사의 실제 브랜드 제품으로 광고처럼 보이는 이미지를 만들어 공개하면 상표권 문제가 생길 수 있으니, 내 제품이나 이름 없는 제품으로 연습하세요.

4장면을 키트로 다듬기 — Midjourney 프롬프트 원칙

하고 싶은 장면을 한국어로 대충 쓰면, 아래 키트가 빠진 요소를 하나씩 물어보고 영어 프롬프트로 다듬어 줍니다. 3차시의 역질문을 그대로 쓰는 방법입니다. 먼저 해 보고, 키트가 무엇을 지켜 줬는지는 실습 뒤에 확인합니다.

실습 C — 실습 B의 유튜버로 스튜디오 광고 만들기
  1. 장면 쓰기 — 실습 B의 유튜버로 스튜디오에서 찍은 광고를 만든다고 생각하고, 한국어로 한두 줄 대충 씁니다 예: 스튜디오 조명을 받으며 선크림을 든 유튜버, 뒤에는 여름 바닷가 사진이 합성된 선크림 광고 / 같은 유튜버 뒤로 햇살 영상이 흐르는 대형 화면이 있는 광고 촬영 현장 / 흰 스튜디오에서 선크림 튜브만 크게 보이는 제품 광고 사진
  2. ChatGPT에 아래 키트를 붙여 넣고, [내 장면]에 쓴 내용을 넣어 실행합니다. ChatGPT가 묻는 질문에 선택지 번호로 답하면 됩니다

5만든 뒤 다듬기 — 생성 작업 버튼

4장 중 하나를 클릭하면 크게 열리고, 오른쪽에 생성 작업 버튼이 나옵니다. 마음에 드는 한 장을 골라 다시 만들지 않고 다듬는 것이 Midjourney 작업의 핵심입니다.

버튼하는 일
다시 실행 — 표준 / 생각같은 프롬프트로 새 4장. 조건은 같아도 결과는 다르게 나옴
변형 — 약하게 / 강하게고른 이미지를 바탕으로 4장을 새로. 약하게는 표정·손·세부만, 강하게는 포즈와 구도까지 바뀜
업스케일 — 약하게 / 창의적크기를 두 배로(1024×1024 → 2048×2048). 약하게는 원본 그대로, 창의적은 질감·세부를 새로 더함
HD — HD로 일괄 생성처음부터 2048 크기의 고해상도로 4장을 다시 만듦. HD 이미지는 업스케일이 따로 없음
프롬프트 사용 — 스타일 / 프롬프트스타일은 이 이미지의 색감·질감·분위기를 새 작업에 가져가고, 프롬프트는 영어 프롬프트를 입력창으로 가져옴
편집 — 빠른 편집 / 편집기 열기빠른 편집은 인물과 구도는 두고 한 줄로 고치기(배경 바꾸기 등). 편집기는 부분만 지우고 다시 그리기 (9차시)
이미지로 비디오 생성 — 자동 / 루프이 이미지를 시작 화면으로 5초 영상 만들기. 자동은 알아서 움직이고, 루프는 처음과 끝이 이어져 반복 재생됨. 각각 약한 모션 / 강한 모션 중에서 고름
