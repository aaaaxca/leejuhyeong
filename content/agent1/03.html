1대화 · Cowork · Claude Code — 뭘 어디에 쓰나

도구마다 잘하는 일이 다릅니다. 한 업무도 단계마다 나눠 맡깁니다.

방식일하는 법잘하는 일이럴 때

세 가지 모두 Claude 데스크톱 앱 하나에서 합니다. 대화와 Cowork는 같은 대화창이고, 결과물을 말하면 맡기기, 질문하면 대화가 됩니다. Claude Code만 앱 사이드바의 Code 탭으로 따로 들어갑니다.

"매주 한다"는 것만으로는 갈리지 않습니다. 갈림길은 매주 반복되는 게 무엇이냐입니다. 문서 작성 · 파일 정리 · 자료 취합이 반복되면 Cowork, 숫자 집계 · 형식 변환이 반복되면 Claude Code입니다. Claude에게 매번 계산을 시키면 같은 질문에도 조금씩 다르게 답할 수 있지만, 계산을 프로그램으로 만들어 두면 같은 파일에 늘 같은 결과가 나옵니다.

2앱을 깔고 폴더를 연결한다

02차시에는 웹에서 파일을 첨부해 맡겼습니다. 오늘은 폴더를 통째로 연결합니다.

웹에서 파일 첨부 (02차시)앱에서 폴더 연결 (오늘)
Claude가 보는 것내가 올린 파일만그 폴더 안 전부 (하위 폴더 포함)
결과물이 생기는 곳대화창 → 직접 내려받기내 폴더에 바로 파일이 생김
파일 이름 바꾸기 · 옮기기불가능가능 — 그래서 조심해야 함
필요한 것웹 브라우저Claude 데스크톱 앱이 켜져 있을 것

맡긴 작업은 내 컴퓨터가 아니라 Anthropic 서버(클라우드)에서 돕니다. 그래서 노트북을 닫아도 작업 자체는 이어집니다. 하지만 내 컴퓨터의 폴더는 데스크톱 앱이 켜져 있을 때만 읽을 수 있고, 필요한 파일의 사본만 클라우드로 가져가 씁니다.

앱을 끄면 폴더를 못 읽습니다

폴더를 맡긴 동안에는 앱을 켜 두세요. 반대로 폴더 접근을 바로 끊고 싶다면 앱을 닫는 것이 가장 빠릅니다.

필요한 것설명
데스크톱 앱폴더 연결은 데스크톱 앱에서만 됩니다. Windows · macOS 지원
폴더 연결과 허락 창입력칸 옆 + 메뉴로 폴더를 추가하면 허락 창(Folder access request)이 뜹니다. 허락한 폴더에서만 Claude가 움직입니다.
결과물을 말하기"○○ 파일로 만들어 줘"처럼 무엇을 만들지 말해야 맡기기가 됩니다. 질문형은 대화로 답만 하는 경우가 많습니다.

화면 구성은 업데이트마다 바뀝니다. 버튼을 못 찾겠으면 앱 안에서 "내 컴퓨터 폴더를 연결해서 작업하려면 어디서 시작해?"라고 물어보세요.

3실습 A 표대로 주간보고 만들기

한 대화창 안에서 맡기기와 대화를 오가고, 처음과 끝은 사람이 맡습니다.

실습 B — 메모 폴더 → 주간보고 초안

강사 화면을 보며 다 같이 진행합니다. 새 대화에서 시작해 한 대화에서 이어 갑니다.

  1. 앱 설치와 자료 모으기 · 사람 — claude.ai/download 에서 데스크톱 앱을 설치하고 쓰던 계정으로 로그인합니다. zip을 바탕화면의 새 폴더 주간보고연습에 풉니다. 자료를 한 폴더에 모으는 것까지가 사람 몫입니다.
  2. 폴더 연결 — 새 대화 → 입력칸 옆 + → 폴더 추가로 주간보고연습을 연결합니다. 허락 창의 경로 끝이 Desktop\주간보고연습인지 확인하고 허용합니다. 아래 체크박스는 체크하지 않습니다. 어떤 폴더를 여는지 매번 확인하는 습관입니다. 허락 창 마지막 문장 "files Claude uses leave your device and are processed on Anthropic's servers" — Claude가 쓰는 파일은 내 컴퓨터를 떠나 서버에서 처리된다는 뜻입니다. 그래서 회사 자료는 회사 정책을 먼저 확인합니다.
  3. 무엇이 있는지부터 · Cowork — 남에게 받은 자료는 뭐가 들었는지 모르니 목록부터 받습니다.
    목록 받기
    이 폴더에 뭐가 들어 있는지 알려 줘. 아직 정리하거나 파일을 만들지는 마.
    확인할 것 · 파일 4개가 다 나왔는지. 빠진 게 있으면 여기서 바로잡습니다
  4. 정리 · 요약 · Cowork — 이제 맡기는 말투로 시킵니다.
    정리 맡기기
    이번 주 메모들을 항목별로 정리해서 메모정리.md로 저장해 줘.
각 항목은 결정됨 / 미정으로 나누고, 어느 파일에서 나온 내용인지 출처를 붙여 줘.
내용이 서로 다르면 하나를 고르지 말고 둘 다 적어 줘.
    확인할 것 · 탐색기로 폴더를 열어 메모정리.md가 실제로 생겼는지. 그다음 항목 2개를 골라 출처 파일과 맞는지 봅니다. 재료가 틀리면 초안도 틀립니다
  5. 강조점 정하기 · 대화 — 이번엔 파일을 만들라고 하지 않고 주고받으며 정합니다.
    대화로 정하기
    메모 정리 중에서 팀장님이 이번 주에 꼭 아셔야 할 것 3가지만 골라 줘. 왜 그게 중요한지 한 줄씩. 아직 파일로 만들지 마.
    확인할 것 · 폴더에 새 파일이 없고 대화로만 답했으면 정상. 마음에 안 들면 "2번 대신 ○○가 더 중요해"처럼 바꿔 말합니다
  6. 초안 조립 · Cowork
    초안 맡기기
    메모 정리와 방금 정한 3가지로 팀장님께 올릴 주간보고 초안을 주간보고_초안.md로 저장해 줘.
첫 줄은 3가지를 한 문장으로, 그다음은 실적 / 진행 중 / 결정 필요 순서로.
실적 칸은 비워 두고 [실적 집계 예정]이라고만 써.
미정 항목은 결정 필요에만 넣고, 항목마다 출처 파일을 붙여 줘.
    실적 계산은 매주 같은 숫자 계산이라 Claude Code 몫입니다. 08차시에 배웁니다
  7. 사람 확인 — 메모정리와 초안을 나란히 놓고, 미정 항목이 '결정 필요'에 다 들어갔는지, 결정된 것처럼 쓰인 게 없는지 봅니다. 표만 보지 말고 첫 줄과 문장 속 날짜까지 읽으세요. 찾았다면 처음부터 다시 만들지 말고 그 부분만 고쳐 달라고 합니다. 예 · "초안에서 7/7을 프로모션 시작일로 단정했는데 기간은 아직 미정이야. '7/7 시작 예정(기간 미확정)'으로 고치고 나머지는 그대로 둬."

4맡기는 법 — 과제 정의가 90%

맡기면 Claude가 다 읽고, 정리하고, 저장까지 끝낸 뒤에야 결과를 보여 줍니다. 처음에 필요한 걸 다 담아야 합니다.

후배에게 일을 맡기고 외근 나갈 때와 같습니다. 다른 점이 딱 하나 있습니다. 사람은 "이건 좀 이상한데요?" 하고 알아서 되묻지만, AI는 말하지 않은 건 그냥 진행할 수 있습니다. 그래서 "애매하면 멈춰"를 더 분명히 넣어야 합니다.

복사본 폴더를 연결합니다. 원본을 바꾸는 작업이면 "이 폴더 안에서만 작업해"를 넣습니다. 결과물 이름을 정해 줍니다. 안 정하면 기존 파일과 겹칠 수 있습니다. 그리고 숫자는 원본과 대조해 검수합니다.

5일하는 흐름 — 계획 → 실행 → 보고

가장 중요한 개입 지점은 실행이 끝난 뒤가 아니라 계획 단계입니다.

실습 C — 영수증 뭉치 → 경비 보고서

영수증 17장을 정리해 팀장님께 정산을 올려야 합니다. 회사 정산 규정은 폴더 안 안내_읽어주세요.txt에 있습니다. 새 대화에서 시작해 실습 D까지 한 대화에서 이어 갑니다.

  1. 폴더 준비 — zip을 새 폴더 경비정리연습에 풀고, 새 대화에서 그 폴더를 연결합니다.
  2. 과제문 초안 직접 써 보기 (3분) — 시키기 전에 내가 맡긴다면 뭐라고 할지 먼저 씁니다. 안내 파일과 이미정산_메모.txt를 1분만 훑고, 메모장에 세 줄로 답합니다. 받고 싶은 결과물은? 규칙은? 애매할 때는? 쓴 메모는 경비정리연습 폴더에 저장하지 마세요. Claude가 영수증 자료로 읽어 버릴 수 있습니다
  3. 과제문 넣고 계획 받기 — 내 초안 대신 아래 과제문을 입력합니다.
    경비 보고서 과제문
