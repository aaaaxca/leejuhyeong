06차시

타이포그래피 + 레이어 스타일

글자를 넣고 다듬은 뒤 레이어 스타일로 질감을 입혀 봅니다.

교재 PS 06·07이론 30 · 실습 70 · 조절 20Photoshop

이론

  • Type Tool — 포인트 문자와 단락 문자, Character · Paragraph 패널
  • Guides — 안내선으로 배치 맞추기
  • Layer Style — 그림자 · 획 · 경사와 엠보스 · 오버레이
  • 스타일 복사·붙여넣기와 저장
🛠 실습 A — 사원증 디자인

순서는 ① 안내선으로 판 나누기 → ② 사진·이름·소속 배치 → ③ 글자 크기·간격 정리.

📎 준비물
  • 증명사진 (제공 파일 또는 본인)
🛠 실습 B — 문자 질감 (크롬·물)

순서는 ① 큰 글자 입력 → ② 레이어 스타일로 크롬 효과 → ③ 물 질감으로 바꿔 비교.

📎 준비물
  • 질감 이미지 (제공 파일)
⏸ 조절 구간 — 글꼴 설치가 안 된 수강생 돕기 / 빠른 수강생은 만든 스타일을 저장해 다른 글자에 적용
📦 오늘 결과물 — 사원증, 문자 질감 2종
