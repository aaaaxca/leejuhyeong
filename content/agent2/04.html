Claude Code 실전 — 반복 도구 · 웹 배포

AI Agent 1 08차시에서 도구를 한 번 만들어 봤습니다. 오늘은 그 도구를 매주 손 안 대고 돌아가는 도구로 키웁니다. 공급사 단가표가 오면 판매가표 · 변동 리포트 · 손님용 가격표 페이지까지 한 번에 나오게 만들고, 일부러 망가뜨려 보고, 저장 지점을 남기고, GitHub Pages로 인터넷 주소에 올립니다.

오늘의 가상 상황

PC 조립 매장 코어랩PC는 사장 혼자 운영합니다. 매주 월요일 공급사가 부품 단가표 엑셀을 보냅니다. 사장은 분류마다 다른 마진을 붙이고, 100원 단위로 맞추고, 품절을 지우고, 지난주보다 많이 오른 부품을 따로 적은 뒤, 매장 카운터에 붙일 가격표를 다시 만듭니다. 매주 40분. 손님이 "요즘 램 얼마예요?" 물으면 그때마다 엑셀을 엽니다. 오늘은 이 월요일 40분을 파일 넣고 한 마디로 줄이고, 손님이 휴대폰으로 보는 가격표 주소까지 만듭니다.

1. 한 번 쓰는 도구 vs 매주 도는 도구

Agent 1에서 만든 도구는 "이번 파일"에서 맞으면 끝이었습니다. 매주 쓰려면 다른 질문이 생깁니다.

한 번 쓰는 도구 (Agent 1 08차시)매주 도는 도구 (오늘)
입력지금 폴더에 있는 그 파일매주 새로 들어오는 파일 — 이름이 바뀜
이상한 데이터눈으로 보고 넘어감언젠가 반드시 옴 — 멈추고 알려야 함
결과csv 하나쓰는 곳마다 다른 모양 (내부용 · 손님용)
고친 뒤지난 버전이 없음망가지면 지난주 상태로 돌아갈 수 있어야 함
실행Claude에게 다시 설명한 마디 (또는 예약 작업 — 03차시)

오늘의 일은 코드를 더 잘 짜는 게 아닙니다. 코드는 Claude Code가 씁니다. 우리가 하는 일은 "다음 주에 무슨 일이 생길 수 있나"를 미리 말해 주는 것입니다.

2. 튼튼한 도구의 요청문 — 네 가지에 두 가지 더

Agent 1에서 배운 입력 · 처리 · 출력 · 예외에 '다음 주'와 '기록'을 붙입니다.

요소묻는 것코어랩PC 예
입력어떤 파일을, 어떻게 찾나이름에 supplier_prices가 들어간 엑셀 중 가장 최근 것
처리무슨 규칙으로pricing_rules.txt의 분류별 마진 · 100원 올림 · 품절
출력누구에게 어떤 모양으로내부용 판매가표 csv · 변동 리포트 · 손님용 가격표 페이지
예외이상하면빈칸 · 글자 섞인 칸은 건너뛰고 로그에

건너뛸 것과 멈출 것을 나눠 주세요

빈칸 한 줄은 건너뛰고 기록하면 됩니다. 그런데 '공급가' 열이 '단가'로 이름이 바뀌었다면? 도구가 알아서 "비슷한 열"을 찾아 계산하면 틀린 가격표가 손님 앞에 붙습니다. 작은 이상은 건너뛰고, 구조가 바뀌면 멈춘다. 이 구분은 AI가 정해 주지 않습니다. 요청문에 직접 적습니다.

3. 가격표 도구 — 오늘의 본편

규칙은 파일에, 계획은 먼저, 결과는 세 갈래로.

실습 A — 폴더 준비와 CLAUDE.md
  1. 폴더 — 바탕화면에 가격표도구 폴더를 만들고 supplier_prices_W46.xlsx와 pricing_rules.txt를 넣습니다. W47 파일은 아직 넣지 않습니다. 실습 D에서 씁니다.
  2. 연결 — Code 탭 → Local · 작업 폴더 가격표도구 · 권한 모드는 수동.
  3. 둘러보기 — "이 폴더의 파일을 보여 주고, 엑셀의 열 이름과 pricing_rules.txt의 규칙을 표로 정리해 줘. 아직 아무것도 만들지 마." 열 5개(분류 · 품명 · 규격 · 공급가 · 재고), 규칙 4개가 나오나
  4. CLAUDE.md — 아래를 보냅니다. 메모장으로 열어 일곱 줄이 다 들어갔는지 봅니다.
규칙 파일
이 폴더에 CLAUDE.md를 만들어 줘. 내용:
① 이 폴더는 코어랩PC의 주간 가격표 폴더다
② 공급사 원본 엑셀은 절대 고치지 않는다
③ 결과는 결과/ 폴더, 손님용 페이지는 site/ 폴더에만 저장한다
④ site/ 폴더에는 공급가 · 마진 · 재고 수량을 절대 넣지 않는다 (판매가와 품절 여부만)
⑤ 나는 비개발자이니 명령을 실행하기 전에 무엇을 하는지 한 줄로 설명한다
⑥ 열 이름이나 파일 구조가 예상과 다르면 추측하지 말고 멈춰서 나에게 묻는다
⑦ csv는 엑셀로 열어도 한글이 깨지지 않게 저장한다

④가 오늘 가장 중요한 줄입니다. 7절에서 site/ 폴더는 인터넷에 공개됩니다. 공급가가 섞여 올라가면 내 원가가 전 세계에 공개됩니다.

준비물
  • 공급사 단가표 · supplier_prices_W46.xlsx (이번 주), supplier_prices_W47.xlsx (다음 주, 실습 D용)
  • 가격 규칙 · pricing_rules.txt, 분류별 마진 · 100원 단위 올림 · 품절 · 변동 표시
실습 B — 새 대화에서 계획 받고 만들기

Code 탭에서 새 대화를 열고 같은 폴더를 고릅니다. 새 대화여야 CLAUDE.md가 자동으로 읽혔는지 확인할 수 있습니다.

도구 요청
매주 월요일에 다시 돌릴 가격표 도구를 만들어 줘.

[입력] 이 폴더에서 이름에 supplier_prices가 들어간 엑셀 중 가장 최근 파일 하나
[처리] pricing_rules.txt의 규칙대로 판매가 계산. 재고 0은 '품절'
[출력]
 1) 결과/판매가표_주차.csv — 분류 · 품명 · 규격 · 공급가 · 판매가 · 상태
 2) 결과/변동리포트_주차.md — 지난주 파일이 있으면 판매가가 5% 이상 바뀐 부품, 새로 생긴 부품, 사라진 부품
 3) site/index.html — 손님용 가격표. 분류별로 묶고 휴대폰에서 잘 보이게. 맨 위에 '기준일'
[예외] 빈칸이나 숫자가 아닌 가격은 그 줄만 건너뛰고 결과/처리로그.txt에 이유와 함께
[다음 주] 파일 이름 · 행 수가 바뀌어도 돌아가게. 열 이름이 다르면 멈추고 알려 줘
[기록] 처리로그.txt에 실행 시각 · 읽은 파일 · 처리한 줄 수 · 건너뛴 줄 수
추가 설치 없이 이 PC에서 돌아가게. 다시 실행하는 법은 사용법.txt에 3줄로.
진행 전에 계획 먼저 보여 줘.

확인할 것 — 계획에 내가 말 안 한 "원본은 고치지 않음", "site/에는 공급가를 넣지 않음"이 나오나요? 나오면 CLAUDE.md가 읽힌 겁니다. 그다음 "좋아, 진행해." 허락 요청마다 한 줄 설명을 읽고 허락합니다.

Python이 없는 Windows PC면 PowerShell 파일(.ps1)로 만들겠다고 합니다. 정상입니다. "설치하지 말고 PowerShell로" 그대로 두세요.

4. 검산 — 경계에서 틀립니다

평범한 숫자는 거의 맞습니다. 틀리는 곳은 규칙이 갈리는 자리입니다.

볼 곳예흔한 실수
올림 vs 반올림RAM 공급가 61,000원 × 1.12 = 68,320원 → 68,400원반올림해서 68,300원
분류별 마진그래픽카드는 6%, RAM은 12%전부 같은 마진, 또는 분류 이름 철자가 달라 기본값 적용
품절재고 0 → '품절', 가격은 그대로 표시줄 자체를 지움 → 손님이 "없어졌나?"
공개 페이지site/index.html에 판매가 · 품절만표를 통째로 옮겨 공급가 열이 따라 들어감
실습 C — 대조표로 검산
검산
방금 도구를 쓰지 말고, 엑셀 원본과 pricing_rules.txt만 보고 분류마다 1개씩 판매가를 직접 계산해서
도구 결과와 나란히 대조표로 보여 줘. 계산식도 같이 적어 줘.
그리고 site/index.html 안에 공급가 · 재고 숫자가 들어 있는지 찾아서 알려 줘.

확인할 것 — 대조표가 전부 일치하나요? 계산기로 2개는 직접 눌러 봅니다. site/index.html을 브라우저로 열고 Ctrl + U(소스 보기) → Ctrl + F로 원본 엑셀의 공급가 숫자 하나를 검색해 봅니다. 화면엔 안 보여도 소스에 숨어 있으면 공개됩니다.

5. 다음 주 미리 겪기 — 일부러 망가뜨리기

도구가 진짜 시험을 받는 건 다음 주 월요일입니다. 오늘 미리 당겨 옵니다.

실습 D — 다음 주 파일과 망가진 파일
  1. 다음 주 — supplier_prices_W47.xlsx를 폴더에 넣고 새 대화에서 "사용법.txt대로 가격표 도구를 실행해 줘." 계산을 새로 짜지 않고 같은 도구를 돌리나. 변동리포트에 오른 부품 · 새 부품이 나오나
  2. 작은 이상 — W47 파일을 복사해 supplier_prices_W48.xlsx로 만들고, 엑셀에서 가격 하나를 지우고 다른 하나에 "문의"라고 적어 저장 → 다시 실행. 그 두 줄만 건너뛰고 처리로그에 남나
  3. 구조 변경 — W48 파일의 '공급가' 열 이름을 '단가'로 바꿔 저장 → 다시 실행. 멈추고 "열 이름이 다르다"고 묻나. 알아서 '단가'로 계산했다면 CLAUDE.md ⑥이 안 지켜진 것
도구의 반응판정할 일
멈추고 묻는다좋음"이번만 '단가'를 공급가로 써" 또는 공급사에 확인
알아서 계산하고 조용히 끝남위험"열 이름이 다르면 계산하지 말고 멈추도록 도구를 고쳐 줘"
오류로 멈추고 영어 메시지만보통"오류가 나면 무엇이 문제인지 한국어 한 줄로 처리로그와 화면에 남기게 고쳐 줘"

실험이 끝나면 W48 파일은 지웁니다. 남겨 두면 다음 실행 때 '가장 최근 파일'로 잡힙니다. 지우는 건 탐색기에서 직접 합니다.

6. 저장 지점 — 고치기 전에 찍어 두기

도구를 고치다 보면 "어제는 됐는데"가 옵니다. 그때 돌아갈 곳이 필요합니다.

개발자들은 git이라는 프로그램으로 폴더의 저장 지점을 찍습니다. 게임의 세이브 포인트와 같습니다. 명령어는 몰라도 됩니다. Claude Code에게 말로 시키면 됩니다.

하고 싶은 것이렇게 말한다
처음 한 번"이 폴더를 git으로 관리해 줘. 엑셀 원본과 결과/ 폴더는 저장 지점에 넣지 마."
고친 뒤"지금 상태를 저장 지점으로 남겨 줘. 메모는 '열 이름 다르면 멈추게 수정'."
무엇을 바꿨나"저장 지점 목록을 날짜 · 메모로 보여 줘."
되돌리기"'열 이름 다르면 멈추게 수정' 전 상태로 도구를 되돌려 줘. 되돌리기 전에 무엇이 바뀌는지 먼저 보여 줘."
대화 되감기와 무엇이 다른가

Claude Code 대화에서도 방금 바꾼 것을 되돌릴 수 있습니다. 하지만 그건 그 대화 안에서만입니다. 다음 주 새 대화에서 "지난주 상태로"는 git 저장 지점이 있어야 됩니다. 7절 GitHub도 이 저장 지점을 그대로 올리는 곳입니다.

실습 E — 저장 지점 두 개 찍기

위 표의 "처음 한 번" → 실습 D에서 도구를 고쳤다면 "고친 뒤"까지 보내고, "저장 지점 목록"으로 두 줄이 보이는지 확인합니다. git이 없으면 설치를 안내합니다. 무엇을 설치하는지 한 줄 설명을 읽고 허락하세요.

7. 웹 배포 — GitHub Pages

Agent 1에서는 Firebase로 올렸습니다. 오늘은 무료로 오래 두기 좋은 GitHub Pages입니다. 05차시에는 말 한 마디로 올리는 AI SPACE를 봅니다.

GitHub Pages (오늘)Firebase (Agent 1 12차시)AI SPACE (05차시)
올리는 법저장소에 올리면 자동명령어로 deployClaude에게 "배포해 줘"
데이터 저장없음 (보여 주기만)FirestoreDB를 말로 추가
비용공개 저장소면 무료무료 한도 안에서 무료체험 뒤 월 요금
대신 내주는 것저장소가 공개됨설정이 많음매달 비용
공개 저장소 = 폴더째 공개

무료 GitHub Pages는 공개 저장소에서만 됩니다. 공개 저장소는 페이지만이 아니라 올린 파일 전부를 누구나 볼 수 있습니다. 그래서 오늘은 도구 폴더 전체가 아니라 site/ 폴더만 따로 올립니다. 공급사 엑셀 · 결과/ · 도구 파일은 올리지 않습니다.

실습 F — 손님용 가격표를 주소로
  1. GitHub 가입 · 사람 — github.com에서 가입하고 이메일 인증까지. 계정 · 비밀번호 화면은 직접 합니다.
  2. Claude Code에 맡기기 — 같은 폴더의 대화에서 아래를 보냅니다.
  3. 로그인 · 사람 — 중간에 GitHub 로그인 창이 브라우저로 뜨면 직접 로그인하고 허용합니다. 비밀번호나 코드를 대화창에 붙여넣지 않습니다.
  4. 확인 — 1~2분 뒤 알려 준 주소를 휴대폰으로 열어 봅니다.
