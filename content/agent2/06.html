06차시

검색 노출 — SEO · AEO · GEO

홈페이지는 올라갔지만 지금은 주소를 아는 사람만 들어옵니다. 모르는 사람이 찾아오려면 검색 목록, 질문의 답 상자, AI 답변 속에 걸려야 합니다. 세 가지를 구분하고, 05차시 뮤지엄 홈페이지를 점검해 검색 요소를 넣고 다시 배포한 뒤, 구글 · 네이버에 "여기 새 사이트 있어요"라고 등록합니다.

오늘의 상황

05차시에 올린 뮤지엄 홈페이지에 아무도 들어오지 않습니다. 당연합니다. 주소를 아는 사람이 우리 반뿐이니까요. 오늘은 홈페이지 내용은 그대로 두고, 검색엔진과 AI가 읽기 쉬운 모양으로 다듬습니다. 체험판 배포 횟수를 아끼기 위해 오늘 배포는 딱 두 번입니다.

1. 검색에 걸리는 세 가지 방식

요즘 사람들이 무언가를 찾는 방법은 셋입니다. 우리 학원을 예로 들어 봅니다.

이름사람이 하는 일우리가 바라는 것
SEO
검색엔진 최적화		네이버 · 구글에 "안산 AI 학원" 검색검색 결과 목록 위쪽에 뜨기
AEO
답변엔진 최적화		"AI 에이전트 수업은 몇 주 걸려요?"처럼 질문으로 검색검색창 위 답 상자나 음성 비서의 답으로 뽑히기
GEO
생성형 엔진 최적화		ChatGPT · Claude · 구글 AI 개요에 "안산에서 AI 배울 곳 추천해 줘"AI 답변 속에 이름이 나오고 출처로 인용되기

셋은 결국 같은 걸 봅니다. 검색엔진도 AI도 페이지를 읽어서 판단합니다. 그래서 할 일은 대부분 겹칩니다.

2. 페이지에 넣을 것

화면에 보이는 것과, 화면엔 안 보이지만 검색엔진이 읽는 것이 있습니다.

넣을 것쉬운 뜻주로 돕는 것
제목 · 설명 메타 태그검색 결과에 보이는 제목과 두 줄 설명SEO
제목 구조 (h1, h2)큰 제목 하나, 그 아래 소제목들. 글의 목차SEO · AEO
글자로 된 내용중요한 말을 이미지가 아닌 글자로셋 다
FAQ (질문과 답)"○○은 뭔가요?" — "○○은 …입니다." 한 문장으로 바로 답AEO · GEO
구조화 데이터 (JSON-LD)"이건 회사 이름, 이건 로고, 이건 질문과 답"이라고 붙인 검색엔진용 꼬리표셋 다
sitemap.xml이 사이트에 어떤 페이지가 있는지 알려 주는 목록SEO
robots.txt검색 로봇에게 "들어와도 돼요 / 여긴 안 돼요"를 알리는 안내문셋 다
공유 미리보기 (OG 태그)카톡 · SNS에 링크를 보냈을 때 뜨는 제목 · 그림검색보다는 공유용
FAQ가 왜 중요한가

사람들이 AI에게 묻는 방식이 질문이기 때문입니다. 페이지에 "뮤지엄은 어떤 브랜드인가요?" — "뮤지엄은 평범한 일상 장면을 짧은 영상으로 전시하는 1인 브랜드입니다."처럼 질문과 한 문장짜리 답이 글자로 있으면 AI가 그 문장을 가져다 쓰기 쉽습니다. 05차시 인터뷰의 7번이 여기서 쓰입니다.

3. 사실대로 알아 둘 것

검색 노출에는 과장된 약속이 많습니다. 수업에서 확인된 것만 정리합니다.

흔한 기대실제
넣으면 바로 뜬다검색엔진이 찾아 읽는 데 며칠~몇 주. 순위는 아무도 보장할 수 없음
FAQ 구조화 데이터를 넣으면 구글에 질문 · 답 모양으로 뜬다구글은 2023년부터 이 모양을 정부 · 의료 같은 일부 사이트에만 보여 줌. 그래도 화면에 글자로 적힌 질문과 답은 AI 답변에 계속 도움
AI 답변에 뽑히는 비법이 있다특별한 비법은 없음. 구글도 AI 개요에 나오려고 따로 할 건 없고 기본 SEO와 좋은 내용이 같다고 안내
llms.txt를 넣으면 AI에 잘 나온다제안된 형식이지만 주요 검색엔진 · AI 회사가 공식 표준으로 쓴다고 밝힌 건 아님. 넣어서 손해는 없지만 효과는 확인되지 않음

반대로 검색에 안 걸려야 하는 페이지도 있습니다. 팀 내부용 회의록 같은 페이지에는 noindex(검색에 넣지 마세요) 표시를 넣습니다.

4. 점검하고 넣고, 다시 배포

진단 → 넣기 → 배포 → 확인. 고치기 전에 지금 상태부터 봅니다.

실습 A — 검색 요소 점검 · 추가 · 두 번째 배포

05차시 '브랜드 홈페이지' Project의 그 대화에서 이어 갑니다. AI SPACE 커넥터가 켜져 있어야 합니다.

① 진단
방금 배포한 홈페이지를 SEO · AEO · GEO 관점에서 점검해 줘.
제목 · 설명 메타 태그, 제목 구조, FAQ, 구조화 데이터, sitemap.xml, robots.txt, 공유 미리보기가
각각 있는지 없는지 표로 보여 줘. 고치는 건 아직 하지 마.
② 넣기
표에서 없다고 나온 것은 넣고, 있어도 아래 조건에 안 맞으면 고쳐 줘.
- 제목은 '뮤지엄(MUSEUM) — 일상을 전시하다.'처럼 브랜드 이름이 먼저, 설명은 두 문장 이내
- 큰 제목(h1)은 하나만
- FAQ는 페이지에 글자로 보이게, 각 답의 첫 문장은 질문에 바로 답하는 한 문장
- 구조화 데이터(JSON-LD)는 Organization(이름 · 로고 · 설명)과 FAQPage
- sitemap.xml과 robots.txt 추가 (robots.txt는 모든 검색 로봇 허용, sitemap 위치 적기)
- 공유 미리보기(OG) 제목 · 설명 · 이미지
- 내가 준 정보만 쓰고, 없는 건 넣지 마
바꾼 곳을 목록으로 보여 주고 아직 배포는 하지 마.
③ 다시 배포 — 오늘의 첫 번째
바꾼 내용으로 같은 주소에 다시 배포해 줘.

④ 확인

  1. 홈페이지에서 Ctrl + U(소스 보기) → Ctrl + F로 <title>, name="description", application/ld+json을 찾습니다.
  2. 주소 뒤에 /robots.txt, /sitemap.xml을 붙여 각각 열리는지 봅니다. sitemap.xml 안의 주소가 실제 주소와 같은지. example.com이 들어 있기도 합니다
  3. validator.schema.org에 주소를 넣고 Organization과 FAQPage가 오류 0개로 나오는지 봅니다.
  4. 카톡 나와의 채팅에 주소를 보내 공유 미리보기(제목 · 그림)가 뜨는지 봅니다.

  • 05차시 홈페이지 주소 · 같은 대화에 있음
  • Schema Markup Validator · validator.schema.org, 무료, 구조화 데이터 오류 검사

5. 검색엔진 등록 — "여기 새 사이트 있어요"

검색엔진은 언젠가 스스로 찾아오기도 하지만, 새 사이트는 직접 알리는 게 빠릅니다. 우리나라에서는 두 곳.

구글 서치 콘솔네이버 서치어드바이저
주소search.google.com/search-consolesearchadvisor.naver.com
등록 방식속성 추가 → URL 접두어 → 홈페이지 주소웹마스터 도구 → 사이트 등록 → 홈페이지 주소
내 사이트인지 증명HTML 태그 한 줄을 페이지에 넣기HTML 태그 한 줄을 페이지에 넣기
등록 뒤 할 일Sitemaps에 sitemap.xml 제출요청 → 사이트맵 제출에 sitemap.xml 제출
왜 '도메인' 방식은 못 쓰나

구글의 '도메인' 방식은 그 주소의 주인만 씁니다. …mycafe24.ai는 카페24 것이라 URL 접두어를 고릅니다. 04차시 …github.io도 같습니다. 내 도메인을 사서 연결했다면 도메인 방식도 됩니다. 주인 증명은 검색엔진이 주는 태그 한 줄(<meta name="google-site-verification" …> 같은 것)을 내 페이지에 넣는 것으로 합니다. "이 페이지를 고칠 수 있는 사람 = 주인"이라는 뜻입니다.

실습 B — 구글 · 네이버에 등록하기

구글은 강사 화면으로 함께 보고, 네이버는 같은 순서로 각자 합니다. 실습 A와 같은 대화에서 이어 갑니다.

  1. 인증 태그 찾아 두기 — 구글 서치 콘솔 → 속성 추가 → URL 접두어에 주소 → 확인 방법에서 HTML 태그. 네이버 서치어드바이저 → 사이트 등록 → 소유확인에서 HTML 태그. 확인 버튼은 아직 누르지 않고 두 탭을 열어 둠
  2. 프롬프트에 붙여넣기 — 아래 프롬프트를 입력창에 붙여넣고(아직 보내지 않음), 구글 탭에서 복사한 태그를 [구글 태그] 자리에, 네이버 탭에서 복사한 태그를 [네이버 태그] 자리에 붙입니다. 두 줄이 다 들어갔는지 보고 보냅니다. 한 번에 넣어 배포 횟수를 아낌 — 오늘의 두 번째 배포
  3. 확인 누르기 — 배포가 끝나면 두 화면으로 돌아가 확인(소유확인)을 누릅니다.
  4. sitemap 제출 — 구글: Sitemaps → sitemap.xml → 제출. 네이버: 요청 → 사이트맵 제출 → sitemap.xml → 확인.

아래 두 줄을 홈페이지 <head> 안에 그대로 넣고, 같은 주소에 다시 배포해 줘. 다른 곳은 바꾸지 마.

7. 정리 · 자주 묻는 질문 · 안 될 때

한 줄 요약

SEO는 목록 위로, AEO는 답으로 뽑히기, GEO는 AI 답변에 인용되기. 셋 다 글자로 된 분명한 내용과 질문 · 한 문장 답에서 시작합니다. 구글 · 네이버에 등록 → 태그로 주인 증명 → sitemap 제출. 결과는 며칠~몇 주 뒤이고, 순위는 아무도 보장하지 못합니다.
