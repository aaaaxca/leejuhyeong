05차시

나만의 선생님 — 영어 회화·배우고 싶은 것

AI를 언제든 물어볼 수 있는 선생님으로 써서, 음성으로 영어 회화를 연습하고 배우고 싶은 것 하나를 시작합니다.

오늘의 상황

해외여행 가서 한마디라도 하고 싶고, 휴대폰 기능은 매번 자녀에게 묻기 미안합니다. 오늘은 AI에게 "천천히, 쉬운 말로, 하나씩" 가르쳐 달라고 해서 영어 회화를 소리 내어 연습하고, 내가 배우고 싶은 것 하나를 시작합니다.

휴대폰 ChatGPT 음성 대화이론 25 · 실습 75 · 조절 20ChatGPT 무료 (음성 제한)

이론

  • 선생님으로 쓰는 말: "천천히" · "쉬운 말로" · "한 번에 하나씩" · "틀리면 고쳐 줘"
  • 답만 받지 말고 문제를 내 달라고 한다 — 퀴즈로 복습
  • 음성 대화는 무료 한도가 있다 → 실습 A에서만 쓰고, B는 글로
  • 휴대폰 사용법도 물어볼 수 있다 — 내 휴대폰 기종을 먼저 알려 주기
🛠 실습 A — 음성으로 영어 회화 5분

순서는 ① "식당에서 주문하는 상황극 해 줘" → ② 소리 내어 따라 하기 → ③ 틀린 곳 고쳐 받기.
휴대폰 앱에서 새 대화로 시작합니다.

📎 준비물
  • 이어폰 · 있으면 · 교실 소음 줄이기
🛠 실습 B — 배우고 싶은 것 하나, 첫걸음

순서는 ① 주제 고르기 → ② "오늘 배울 것 3가지만" 받기 → ③ 퀴즈 3문제 풀기.
새 대화에서 시작합니다. 주제 예: 손주와 영상통화, 사진 잘 찍기, 한자, 악기.

📎 준비물
  • 배우고 싶은 것 1가지 · 메모
⏸ 조절 구간 — 음성 대화 켜기 돕기 / 빠른 수강생은 일주일 연습 계획 받기
📦 오늘 결과물 — 영어 회화 연습 기록, 내 공부 첫걸음과 퀴즈
