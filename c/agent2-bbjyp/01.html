AI Agent 2 · 01차시

내 업무 분해하기

자동화할 일 고르기

AI Agent 1에서는 일 하나씩 맡기는 법을 배웠습니다. AI Agent 2에서는 내 업무 하나를 끝까지 자동화하고, 홈페이지 · 블로그 · 인스타처럼 밖으로 내보내는 데까지 갑니다. 오늘은 그 출발점입니다. 업무를 단계로 쪼개 단계마다 도구를 배정하고, 점수를 매겨 무엇부터 자동화할지 고릅니다. 오늘 고른 한 가지가 02 · 03차시의 재료이고, 12차시 최종 프로젝트의 후보입니다.

오늘의 가상 상황

짧은 영상을 만드는 1인 브랜드 뮤지엄(MUSEUM)을 준비하는 사람이 있습니다. 혼자 기획하고, 찍고, 편집하고, 올리고, 홍보하고, 문의에 답하고, 숫자를 봅니다. "AI로 자동화하면 된다"는 말은 많이 들었는데, 무엇부터 해야 할지 모릅니다. 다 하려다 아무것도 못 합니다. 오늘은 일을 쪼개서 자동화할 자리와 사람이 남을 자리를 가릅니다.

2. 준비 점검 — Agent 1에서 만든 연결이 살아 있나

Agent 2는 연결이 끊겨 있으면 시작부터 막힙니다. 10분만 씁니다.

실습 A — 5분 점검
  1. 요금제 — 설정에서 Pro 이상인지. 예약 작업 · Claude Code · 커스텀 커넥터가 모두 유료 기능입니다.
  2. 데스크톱 앱 — 최신 버전으로 업데이트. 사이드바에 Code 탭이 보이나.
  3. 커넥터 — 새 대화에서 아래를 보냅니다.
연결 점검
지금 이 대화에서 쓸 수 있는 커넥터를 목록으로 보여 주고,
Gmail · 구글 캘린더 · 카카오톡이 각각 실제로 동작하는지 읽기만 하는 동작으로 하나씩 확인해 줘.
(메일은 최근 1통 제목만, 캘린더는 오늘 일정 개수만, 카톡은 연결 여부만)
아무것도 보내거나 바꾸지 마.

확인할 것 — 셋 다 '동작함'인가요? "인증이 만료됐다"면 설정 → 커넥터에서 다시 연결합니다. 예약 작업이 아침에 안 오는 가장 흔한 이유가 이것입니다. 지금 고쳐 두면 03차시가 편합니다.

3. 도구 다섯 — 누가 어떤 일을 잘하나

Agent 1에서 하나씩 배운 것을 한 표에 놓습니다. 경쟁이 아니라 분업입니다.

"매주 한다"만으로는 갈리지 않습니다

매주 반복되는 게 문서 · 정리면 Cowork나 스킬, 숫자 계산이면 Claude Code입니다. Claude에게 매번 계산을 시키면 같은 질문에도 조금씩 다르게 답할 수 있지만, 프로그램으로 굳히면 같은 파일에 늘 같은 결과가 나옵니다.

이렇게 고르면생기는 일

4. 업무 분해 — 이름 하나를 단계 여럿으로

"인스타 운영"은 자동화할 수 없습니다. "매주 월요일 지난주 게시물 숫자 모으기"는 됩니다.

쪼갤 때 볼 것예 — 뮤지엄 "새 영상 올리고 알리기"
무엇이 들어오나 (입력)편집 끝난 영상 파일, 장면 메모
무엇이 나가나 (출력)유튜브 설명란 · 인스타 캡션 · 블로그 글 · 해시태그
언제 시작되나 (계기)영상이 완성됐을 때 / 매주 목요일
어디서 판단이 들어가나썸네일 문구, 어떤 장면을 강조할지
어디서 밖으로 나가나업로드 · 게시 버튼을 누르는 순간
실습 B — 뮤지엄 업무 분해하고 도구 배정하기

새 대화에서 시작합니다. 대화 이름은 '01차시 업무 분해'.

업무 분해
내 업무는 '새 영상 올리고 알리기'야.
업무 설명: 1인 브랜드 뮤지엄을 운영한다. 매주 짧은 영상 1편을 편집해 유튜브 쇼츠와 인스타 릴스에 올리고,
같은 내용을 블로그 글로도 쓴다. 다음 주 월요일엔 지난주 영상의 조회 · 저장 숫자를 보고 다음 기획에 반영한다.

이 업무를 6~8개 단계로 나누고, 각 단계를 [사람 / 대화 · Project / Cowork / Claude Code / 커넥터 / 예약 작업] 중
무엇으로 하면 좋을지 표로 정리해 줘. 둘 이상이면 '예약 + 커넥터'처럼 같이 적어.
열: 단계 / 입력 / 출력 / 담당 / 배정 이유 한 줄 / 밖으로 나가나(예·아니오)
규칙:
- 최종 판단 · 승인 · 공개 · 돈이 오가는 단계는 사람
- '매주 반복'이라는 이유만으로 Claude Code에 넣지 말고, 숫자 계산일 때만
- 설명에 없는 부분은 지어내지 말고 나에게 물어봐

확인할 것 — 세 가지만 보세요. ① '밖으로 나가나'가 '예'인 줄의 담당에 사람이 있나. ② Claude Code는 숫자 집계 단계에만 갔나. ③ 촬영 · 편집처럼 AI가 못 하는 단계를 AI에게 맡기지 않았나. Claude가 되물으면 아는 만큼 답합니다. 단계 이름은 매번 조금씩 달라도 괜찮습니다.

5. 자동화 점수 — 무엇부터 할까

쪼갠 단계를 다 자동화할 필요는 없습니다. 효과는 크고 사고는 작은 것부터.

기준1점3점5점
빈도한 달에 한 번 이하매주매일
1회 시간5분 이하15~30분1시간 이상
규칙성 (매번 같은 방식인가)매번 다름틀은 같고 내용만 다름완전히 같음
안전 (틀려도 괜찮나)공개 · 돈 · 고객에게 바로팀 · 나에게 먼저나만 봄, 쉽게 되돌림

네 칸을 더한 점수가 높을수록 먼저 자동화합니다. 안전 점수가 1점인 단계는 총점이 높아도 통째로 맡기지 않습니다. 앞 단계(초안 · 리포트)까지만 자동화하고 마지막은 사람이 누릅니다.

실습 C — 점수 매기고 하나 고르기

실습 B와 같은 대화에서 이어 갑니다.

점수표
방금 표의 각 단계에 빈도 · 1회 시간 · 규칙성 · 안전을 1~5점으로 매겨서 총점 순으로 다시 정렬해 줘.
점수 기준: [위 표를 그대로 붙여 넣기]
빈도와 1회 시간은 내가 말한 것만 쓰고, 모르면 [확인필요]로 두고 나에게 물어봐.
마지막에 '지금 자동화하기 좋은 1순위'와 '자동화하면 안 되는 단계'를 하나씩 이유와 함께 적어 줘.

확인할 것 — 1순위가 "안전 1점"짜리라면 그대로 받지 말고 "공개 직전까지만 자동화하는 버전으로 1순위를 다시 정해 줘". 대부분 반에서 '영상 홍보 문구 패키지 만들기'(설명란 · 캡션 · 해시태그 초안)가 올라옵니다. 02차시에 이걸로 스킬을 만듭니다.

6. 자동화 사다리 — 한 번에 꼭대기로 가지 않는다

사다리는 한 칸씩. 칸마다 사람이 확인하는 자리가 하나씩 줄어드니, 앞 칸에서 충분히 믿을 만해졌을 때 올라갑니다.

칸모습사람이 하는 일배우는 곳
0매번 처음부터 손으로 / 매번 새로 설명전부—
1지시문을 저장해 두고 붙여넣기시작 · 검수 · 실행Agent 1 02
2스킬 — "이번 주 홍보 패키지 만들어 줘" 한 마디시작 · 검수 · 실행02
3예약 — 정해진 때 알아서 초안까지검수 · 실행03
4예약 + 내보내기까지가끔 점검되돌리기 쉬운 일만
사람이 남는 자리 네 곳

판단(무엇을 강조할지) · 승인(이대로 가도 되나) · 공개(올리기 · 보내기 버튼) · 책임(틀렸을 때 누가 고치나). Agent 2 내내 이 네 곳은 사람에게 남깁니다. 자동화가 잘될수록 이 자리를 빼고 싶어지는데, 그때가 사고가 나는 때입니다.

7. 내 업무로 — 자동화 후보 카드

뮤지엄은 연습이었습니다. 이제 내 일입니다.

실습 D — 내 업무 3개 → 후보 카드 1장
  1. 업무 3개 — 반복되는 내 업무 3개를 업무 이름 + 설명 두 줄로 적습니다. AI는 내 업무를 모르니 설명 두 줄이 있어야 제대로 쪼갭니다
  2. 분해 · 점수 — 실습 B · C 프롬프트에서 업무 이름과 설명만 바꿔 셋 다 돌립니다.
  3. 후보 카드 — 셋 중 하나를 골라 아래로 정리합니다.
후보 카드
지금까지 나눈 세 업무 중 '[고른 업무]'를 자동화 후보로 정했어.
아래 칸으로 '자동화 후보 카드' 한 장을 만들어 줘. 표 하나로.
- 업무 이름 / 지금 걸리는 시간(주 단위)
- 자동화할 단계 (사다리 몇 칸까지 갈지)
- 사람이 남는 단계 (판단 · 승인 · 공개 · 책임 중 무엇)
- 입력 자료와 그게 지금 어디 있는지
- 필요한 연결 (커넥터 · 폴더)
- 틀리면 생기는 일 한 줄
- 성공 기준 한 줄 (예: 매주 목요일 오전에 초안이 메일함에 있다)
내가 말하지 않은 숫자는 [확인필요]로.

확인할 것 — '성공 기준'이 눈으로 확인할 수 있는 문장인가요? "편해진다"가 아니라 "매주 ○요일 ○시에 ○○이 ○○에 있다"처럼. 카드는 복사해 메모장에 저장해 둡니다. 02차시에 그대로 씁니다.

준비물
  • 내 업무 3가지 메모 · 업무 이름 + 설명 두 줄씩, 회사 업무가 어렵다면 개인 일(가계부 · 동호회 공지 등)도 좋음
조절 구간 — 빠른 수강생은 커넥터로 반복 업무를 찾아보기. "지난 2주 내 구글 캘린더 일정과 Gmail 보낸편지함 제목만 보고, 반복되는 업무 후보 5개를 뽑아 줘. 횟수 근거를 같이 적고, 추측은 추측이라고 표시해. 메일 본문은 읽지 마." 내가 몰랐던 반복 업무가 나오는지 봅니다.

8. 정리 · 자주 묻는 질문

한 줄 요약

업무 이름은 자동화할 수 없고 단계는 자동화할 수 있습니다. 쪼개서 도구를 배정하고, 빈도 · 시간 · 규칙성 · 안전으로 점수를 매기고, 사다리는 한 칸씩. 판단 · 승인 · 공개 · 책임은 사람에게 남깁니다.

질문답
점수가 다 비슷하게 나와요1회 시간을 실제로 재 보세요. 감으로 쓴 시간은 대개 짧게 적힙니다. 다음 주에 한 번 재고 다시 매기면 갈립니다.
