Maya 7 · 01차시

ComfyUI(Stability Matrix)

설치와 기본 노드·Checkpoint·LoRA

Stability Matrix로 ComfyUI를 설치하고, 기본 노드 흐름으로 이미지를 만든 뒤 Checkpoint·프롬프트·이미지·LoRA를 바꿔 가며 결과를 비교합니다.

Stability Matrix · ComfyUI · CivitAI · ChatGPT

이론

  • Stable Diffusion — 텍스트를 입력하면 AI가 이미지를 만들어 주는 생성형 AI 모델
  • Stability Matrix — Stable Diffusion 관련 프로그램을 설치·관리하는 런처(매니저)
  • ComfyUI — 이미지 생성 과정을 노드로 연결해 파이프라인을 직접 만드는 툴
  • 기본 흐름: Checkpoint → Prompt(긍정/부정) → Empty Latent Image(잠재 공간) → KSampler(섞기) → VAE Decode(수치를 이미지로) → Save Image(결과)
실습 A — 설치
  1. Python 검색 → Downloads → Windows → 최신 Windows installer(64-bit) 설치. Add python.exe to PATH 체크
  2. Git 검색 → Downloads → Windows → Click here to download → 설치. 마지막에 View Release Notes 체크 해제 → Finish
  3. Stability Matrix 검색 → Lykos AI → Downloads → Windows → 설치할 위치에 압축 풀기(D 드라이브도 가능)
  4. StabilityMatrix.exe 실행 → Portable Mode(파일이 있는 경로에 설치) → Share Analytics → ComfyUI → Download → 기다리면 Packages 목록에 ComfyUI 표시

실습 B — 실행하고 오류 확인하기
  1. Launch → 브라우저에서 http://127.0.0.1:8188 열기
  2. 왼쪽 위 Settings → Comfy: 언어 / LiteGraph: 연결선 모양 Linear
  3. Unsaved Workflow 탭을 닫으면 기본 노드가 나타남 → Run
  4. Checkpoint 모델이 없어서 오류가 나는 것을 확인

누락된 모델 — 오류가 나는 이유

  • 워크플로를 열면 Setup required · Missing Models 창이 뜬다. 워크플로에 필요한 모델이 컴퓨터에 없다는 뜻이고, 없으면 실행 시 오류가 난다
  • 창의 Download(또는 Download all)로 받으면 맞는 폴더에 저장된다. 옆의 링크 아이콘은 주소 복사, 과녁 아이콘은 그 모델을 쓰는 노드로 이동(다른 모델로 바꿔 끼울 때)
모델역할비유
Text Encoder (CLIP) — 예: qwen_3_4b프롬프트를 AI가 이해하는 숫자로 바꿈통역사
Diffusion Model — 예: z_image_turbo그 숫자를 보고 노이즈에서 그림을 그림화가
VAE — 예: aeAI 내부의 압축된 그림을 사람이 보는 이미지로 바꿈인화기
왜 이렇게 무거운가

누락된 모델을 받으면 되지만 용량이 매우 큽니다(Z-Image Turbo는 약 19GB). 최신 모델이라 그렇습니다. 옛날 DreamShaper(SD1.5)는 세 개가 합쳐져 있어도 2GB 정도였는데, Z-Image는 통역사부터 언어 모델(Qwen) 하나를 통째로 씁니다. 그래서 긴 문장이나 한글 프롬프트를 훨씬 잘 알아듣고 품질도 좋지만, 그만큼 무겁습니다.

  • Load Checkpoint 하나로 불러오는 모델(SD1.5·SDXL) = 모델·CLIP·VAE가 파일 하나에 합쳐진 것
  • Load Diffusion Model / Load CLIP / Load VAE 셋으로 나뉜 모델(Z-Image·Flux 등) = 세 파일을 따로 배포하는 최신 모델
실습 C — Checkpoint 받아서 실행하기
  1. CivitAI 홈페이지 → Models → Filter: All Time · Checkpoint · SD 1.5
  2. DreamShaper, Realistic Vision V6.0 다운로드
  3. C:\Users\사용자이름\Documents\ComfyUI\models\checkpoints 경로에 넣기
  4. ComfyUI 화면에서 R키로 새로고침(목록에 안 보이면 Custom Node Manager → Restart 또는 ComfyUI 재실행)
  5. Load Checkpoint에서 DreamShaper → Run, Realistic → Run 해서 비교. Save Image 노드는 Ctrl+C → V로 복제, 노드 연결·해제 연습
DreamShaperRealistic Vision V6.0
잘하는 것만능형 — 일러스트·판타지·반실사실사 전문 — 사진 같은 인물·피부·조명
느낌깔끔하고 그림 같은 이미지카메라로 찍은 듯한 사진

Realistic Vision에서 noVAE 버전을 받으면 색이 뿌옇게 나올 수 있습니다. VAE가 포함된 버전을 받으세요.

결과 이미지 위치

Assets 패널에서 확인하고, 파일은 C:\Users\사용자이름\Documents\ComfyUI\output에 있습니다. Save Image 노드에 보이는 이미지는 껐다 켜면 사라집니다. CivitAI에서 마음에 드는 결과물을 열면 오른쪽에 Prompt와 KSampler 수치(Other metadata)가 나와 그대로 참고할 수 있습니다.

실습 D — 프롬프트 다듬기

Checkpoint는 Realistic, Empty Latent는 W 512 · H 768.

  1. 일반 프롬프트 — 긍정: masterpiece, best quality, a handsome young man, forest, cloth / 부정: text, watermark, low quality
  2. ChatGPT에 위 프롬프트에 어울리는 옷·카메라 앵글을 물어보고 나온 단어를 적용
  3. Fixed는 같은 인물로 분위기만, Randomize는 다른 인물로 바뀌는 것 비교

순서: 퀄리티 → 피사체 → 장소 → 복장 → 카메라 → 조명 → 색감

퀄리티masterpiece, best quality, ultra detailed, photorealistic
피사체 + 장소handsome young man in forest
복장earth tone forest ranger outfit, realistic fabric detail
카메라medium shot, three-quarter view, 85mm lens, shallow depth of field — 허리 위·45도, 인물 왜곡이 거의 없는 화보용
조명soft sunlight through trees, warm natural lighting
색감cinematic color grading
실습 E — 이미지로 Latent 지정하기
  1. Load Image — 원하는 분위기의 사진 불러오기
  2. Resize(comfyui_essentials, Stability Matrix → Extension에서 설치) — 8의 배수 크기, Method: Pad(비율이 안 맞는 여백을 채움) / Crop(원본 비율 유지), Multiple_of: 2
  3. VAE Encode — Load Image(IMAGE) → pixels, Load Checkpoint(VAE) → vae, LATENT → KSampler(latent_image)
  4. KSampler denoise 조절 — 낮을수록 원본 이미지와 비슷, 높을수록 프롬프트 쪽 특징만 가져감
  5. 왼쪽 위 아이콘 → File → Save(덮어쓰기) / Save As(다른 이름, 예: Basic)
실습 F — LoRA 적용하기

프롬프트만으로는 표현에 한계가 있습니다. 학습된 LoRA 모델로 디테일을 더합니다.

  1. CivitAI에서 받기 — 디테일: Add More Details / 빛: Light Control - Back Front(+ 정면, − 후면) / 손: Hand Detail / 얼굴: Real Face 계열
  2. C:\Data\Models\Lora로 옮기기(이름 변경 가능) → 재실행
  3. Checkpoint 관련 노드 전체 선택 → Ctrl+C → V로 복제 → Group으로 Checkpoint / Lora 나누기(Edit Group에서 색·크기)
  4. Load LoRA 노드 — Checkpoint → LoRA, LoRA → KSampler·CLIP 연결. strength_model(이미지 강도) 0.5, strength_clip(프롬프트 해석 강도) 0.5
  5. Image Compare 노드(Stability Matrix → Extension에서 설치) — VAE Decode 두 개를 연결해 A/B 비교
