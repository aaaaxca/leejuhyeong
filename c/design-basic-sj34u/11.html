변형·정렬·색상

회전·반사·크기 변형과 정렬, 색상 도구로 반복 그래픽을 만들어 봅니다.

교재 IL 03·04Illustrator

이론

  • Rotate · Reflect · Scale · Shear, 기준점 바꾸기
  • 반복 변형(Ctrl+D)
  • Align — 정렬과 분포
  • Swatches · Recolor Artwork · Gradient
실습 A — 기하학적 선 만들기

순서는 ① 선 하나 그리기 → ② 회전 복사 반복 → ③ 색 바꿔 패턴처럼.

준비물
  • 없음
실습 B — 그레이디언트 화병

순서는 ① 화병 모양 그리기 → ② 그레이디언트 적용 → ③ Recolor로 색 조합 바꾸기.

준비물
  • 화병 참고 이미지 (제공 파일)
조절 구간 — 기준점 바꾸기가 어려운 수강생 돕기 / 빠른 수강생은 Recolor로 색 조합 3가지 만들기
