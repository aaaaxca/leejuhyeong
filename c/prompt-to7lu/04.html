ChatGPT 이미지 생성·편집

로고부터 기획안까지

2차시에는 내 사진을 바꿔 봤다면, 오늘은 이미지를 분석하고, 처음부터 만들고, 원하는 부분만 고칩니다. 가상의 가게 로고를 만들어 다듬은 뒤, 마지막에는 캔버스에서 로고 기획안으로 정리합니다.

1들어가며 — 오늘 만들 것

2차시에서는 내 사진을 다른 그림체로 바꾸는 것을 해 봤습니다. 오늘은 ChatGPT의 이미지 기능을 처음부터 끝까지 써 봅니다.

  1. 보고 분석하기 — 잘 만든 이미지를 보여 주고 무엇이 좋은지 말로 풀게 하기
  2. 처음부터 만들기 — 가상의 가게 로고를 글로 설명해 만들기
  3. 부분만 고치기 — 마음에 안 드는 곳만 골라 다시 그리기
  4. 기획안으로 묶기 — 캔버스에서 로고 기획안 문서 만들기
준비물①잘 만들었다고 생각하는 로고나 포스터 사진 1장

이미지 생성은 요금제마다 한도가 있습니다. 한도에 닿으면 안내된 시간 뒤에 다시 하거나, 옆 사람과 결과를 함께 보며 진행하세요.

2이미지 분석 — 보여 주고 말로 풀게 하기

ChatGPT는 이미지를 보고 이해할 수도 있습니다. 사진, 스크린샷, 포스터, 표를 올리고 질문하면 내용을 읽고 해석해 줍니다. 만들기 전에 좋은 예를 분석해 두면, 내가 원하는 것을 말로 설명하기가 훨씬 쉬워집니다.

실습 A — 잘 만든 이미지 분석하고 거꾸로 프롬프트 뽑기
  1. 입력창의 + 버튼으로 준비한 로고나 포스터 사진을 올리고 실행 
    이 디자인을 실제 손님 입장에서 분석해줘.
1. 잘 된 부분
2. 헷갈릴 수 있는 부분
3. 개선하면 좋을 점
색, 글꼴, 배치, 분위기를 기준으로 표로 정리해줘.
  2. 같은 대화에서 이어서 실행 
    이 이미지와 비슷한 분위기의 이미지를 새로 만들려면 어떤 프롬프트를 쓰면 좋을지, 대상 · 스타일 · 색 · 구도 · 글자로 나눠서 써줘
  3. AI가 뽑아 준 대상 · 스타일 · 색 · 구도 · 글자 다섯 칸을 메모해 두기 — 3번 섹션에서 그대로 씁니다

3이미지 만들기 — 이미지에서는 무엇을 말해 줘야 할까

2차시의 5가지 재료가 이미지에서는 이렇게 바뀝니다. 실습 A에서 AI가 나눠 준 칸과 같습니다.

칸말해 줄 것예
대상무엇을, 누구를 위해동네 카페 '모퉁이'의 로고
스타일그림체, 분위기심플한 라인 아이콘, 따뜻하고 아늑한 느낌
색쓸 색, 색 수베이지와 짙은 갈색 두 가지
구도배치, 비율, 배경정사각형, 가운데 정렬, 흰 배경
글자들어갈 글자와 글꼴 느낌아래에 영문 'MOTUNGI COFFEE', 둥근 고딕체

ChatGPT에서 이미지를 만드는 방법은 두 가지입니다.

  • 입력창의 + 버튼 → 이미지 만들기를 고른 뒤 설명하기
  • 그냥 대화하듯 "~한 이미지를 만들어줘"라고 쓰기

ChatGPT 이미지는 그림 속 글자를 비교적 정확하게 넣는 편이라, 로고·포스터·안내문처럼 글자가 들어가는 이미지에 잘 맞습니다.

4로고 만들기

실습 B — 짧게 한 번, 칸을 채워 한 번

각각 새 채팅에서 실행해 비교하세요.

  1. 짧게 
    카페 로고 만들어줘
  2. 다섯 칸을 채워서 
    동네 작은 카페 '모퉁이'의 로고를 만들어줘.
스타일: 골목 모퉁이에 있는 커피잔을 표현한 심플한 라인 아이콘, 따뜻하고 아늑한 느낌
색: 베이지와 짙은 갈색 두 가지만
구도: 정사각형, 가운데 정렬, 흰 배경
글자: 아이콘 아래에 영문 'MOTUNGI COFFEE', 둥근 고딕 느낌
  3. 내 가게로 바꾸기 — 2번 프롬프트에서 가게 이름·업종·분위기를 내가 정한 것으로 바꿔 다시 실행 (예: 꽃집, 문구점, 1인 디자인 스튜디오)

결과가 마음에 들 때까지 다시 만들기를 반복하기보다, 다음 섹션처럼 부분만 고치는 것이 빠르고 한도도 아낍니다.

5부분만 고치기 — 선택 도구와 올린 이미지 편집

전체를 다시 만들면 마음에 들었던 부분까지 바뀌어 버립니다. 고치고 싶은 곳만 골라 다시 그리게 하세요.

방법이렇게
선택해서 고치기만든 이미지를 클릭 → 선택 도구로 고칠 부분을 칠함 → "이 부분을 ~로 바꿔줘"
말로 고치기"나머지는 그대로 두고, 글자 색만 짙은 초록으로 바꿔줘"처럼 바꿀 것과 둘 것을 함께 말함
올린 이미지 고치기내가 가진 이미지를 올리고 "배경만 흰색으로", "이 글자를 ~로 바꿔줘"
실습 C — 실습 B의 로고 다듬기
  1. 실습 B에서 만든 로고를 클릭 → 선택 도구로 커피잔 부분만 칠하고 실행 
    이 부분의 커피잔에 김이 모락모락 나는 모양을 더해줘
  2. 같은 대화에서 말로 고치기 
    나머지는 그대로 두고, 글자 색만 짙은 초록으로 바꿔줘
  3. 활용 이미지 만들기 — 로고를 실제로 쓴 모습 보기 
    이 로고를 그대로 써서, 테이크아웃 컵과 가게 간판에 적용한 모습을 각각 보여줘
  4. 마음에 드는 이미지를 다운로드해 두기 — 6번 섹션 기획안에 씁니다

한 번에 여러 곳을 고치라고 하면 엉뚱한 곳까지 바뀌기 쉽습니다. 한 번에 하나씩 고치세요.

6캔버스로 로고 기획안 만들기

캔버스는 ChatGPT와 함께 문서를 쓰고 고치는 작업 공간입니다. 대화창 옆에 문서가 따로 열려서, 직접 고치거나 원하는 부분만 다시 쓰게 할 수 있습니다. 오늘 만든 로고를 한 장짜리 기획안으로 정리해 봅니다.

실습 D — 캔버스에서 기획안 쓰고 다듬기
  1. 로고를 만든 대화에서 이어서 실행 — 오른쪽에 캔버스 문서가 열립니다 
    캔버스에서, 지금까지 만든 '모퉁이' 카페 로고의 기획안을 한 장짜리 문서로 만들어줘.
항목: 브랜드 이름 / 로고 콘셉트 / 색상과 그 이유 / 글꼴 느낌 / 로고 활용 예(컵, 간판, SNS) / 앞으로 만들 것
표와 짧은 설명을 섞어서 정리해줘.
  2. 직접 고치기 — 문서를 클릭해 브랜드 이름이나 문장을 직접 고쳐 보기
  3. 부분만 다시 쓰게 하기 — '로고 콘셉트' 문단을 드래그해 선택 → 나타나는 입력칸에 "더 짧고 감성적으로"
  4. 수정 제안 — 오른쪽 아래 편집 버튼에서 수정 제안을 눌러 AI가 단 의견을 보고, 받아들일 것만 적용
  5. 다운로드 — 완성한 기획안을 파일로 내려받기

캔버스의 버튼 이름과 위치는 업데이트로 바뀔 수 있습니다. 로고 이미지는 다운로드한 파일을 문서에 함께 붙여 두면 기획안이 완성됩니다.

73차시 카드뉴스를 이미지로 — 골목분식 신메뉴

3차시에서 받은 신메뉴 카드뉴스 문구를 이번에는 이미지로 만들어 봅니다. 로고 때와 같은 칸(스타일 · 색 · 구도 · 글자)으로 말하고, 한 장씩 만들어 이어 가면 카드의 분위기가 같아집니다.

실습 E — 신메뉴 카드뉴스 이미지 만들기
  1. 문구 준비 — 3차시에서 받은 카드 6장 문구를 이 대화에 가져옵니다. 3차시 대화가 남아 있으면 거기서 이어서 하고, 없으면 문구를 붙여 넣고 시작합니다.
  2. 1장(표지)만 먼저 
    위 카드뉴스 문구 중 1장(표지)을 인스타그램 카드 이미지로 만들어줘.
스타일: 따뜻한 일러스트 느낌, 김이 나는 치즈 떡볶이 그릇
색: 주황과 크림색 두 가지만
구도: 세로 4:5 비율, 제목은 위쪽 가운데, 음식은 아래쪽
글자: 1장 제목을 위 문구 그대로 정확히, 굵은 둥근 고딕 느낌
  3. 같은 스타일로 이어서 — 같은 대화에서 실행 
    방금 만든 1장과 같은 스타일 · 색 · 글꼴 느낌으로 2장을 만들어줘.
글자: 2장 제목을 위 문구 그대로 정확히
  4. 글자 틀린 곳만 고치기 — 한글이 문구와 다르게 나왔다면 
    2장의 제목 글자만 위 문구와 똑같이 고쳐줘. 나머지는 그대로 둬.
  5. 마음에 드는 카드를 다운로드해 두기

6장을 한 번에 만들라고 하면 카드마다 분위기가 달라지고 글자도 틀리기 쉽습니다. 한 장씩 만들고, 글자는 틀릴 수 있으니 꼭 문구와 비교하세요.
