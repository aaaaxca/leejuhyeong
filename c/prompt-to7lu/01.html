AI 변천사와 생성형 AI 이해

AI가 70년 동안 어떻게 지금까지 왔는지 흐름을 잡고, AI가 "예제를 보고 배운다"는 것을 직접 AI를 학습시켜 보며 체감합니다. 이어서 이 수업에서 쓸 ChatGPT · Midjourney · Kling이 어떻게 다른지 알아보고, 세 도구에 가입해 직접 글·이미지·영상을 만들어 봅니다.

1AI는 70년 넘게 쌓인 이야기

AI는 갑자기 하늘에서 떨어진 기술이 아닙니다. 사실 70년 넘게 쌓인 이야기입니다. 짧게 풀어 볼게요.

  • 1950“기계가 생각할 수 있을까?”

    수학자 앨런 튜링이 질문을 던집니다. “기계가 사람처럼 대화해서, 상대가 사람인지 기계인지 구분 못 하면, 그건 생각하는 것 아닌가?” — 이게 그 유명한 튜링 테스트입니다. 컴퓨터도 제대로 없던 시절에 이미 “생각하는 기계”를 상상한 거죠. 영화 〈이미테이션 게임〉의 그 인물입니다.

  • 1956‘AI’라는 단어가 태어나다

    미국 다트머스 대학에 학자들이 모여 한 학문 분야를 출범시킵니다. 이때 처음 “Artificial Intelligence(인공지능)”라는 이름이 붙습니다. “몇 년만 연구하면 사람처럼 똑똑한 기계를 만들 수 있다”는 자신감이 넘쳤습니다. (결과적으로 몇 년이 아니라 수십 년이 걸렸지만요.)

  • 1974–1993‘AI 겨울’

    현실은 호락호락하지 않았습니다. 기대만큼 성과가 안 나오자 투자가 끊기고, 연구가 얼어붙는 시기가 여러 번 옵니다. 이걸 “AI 겨울(AI Winter)”이라 부릅니다. AI는 한동안 “말만 거창하고 안 되는 것”의 대명사였습니다.

  • 1997딥블루, 체스 챔피언을 꺾다

    IBM이 만든 체스 전용 컴퓨터 딥블루가 세계 체스 챔피언 가리 카스파로프를 이깁니다. “기계가 인간 챔피언을 이겼다”는 첫 상징적 사건이었지만, 딥블루는 체스만 할 줄 아는 기계였습니다. AI 겨울 속에서도 좁은 분야(narrow AI)는 조용히 발전하고 있었다는 걸 보여 준 사건입니다.

  • 2012딥러닝이 판을 뒤집다

    컴퓨터 성능(특히 게임용 칩이던 GPU)과 인터넷 데이터가 폭발하면서, 딥러닝이라는 방식이 이미지 인식 대회에서 압도적 성적을 냅니다. “AI가 드디어 쓸 만해졌다”는 신호탄이었습니다. 사진 속 고양이를 사람보다 잘 찾기 시작한 게 이 무렵입니다.

  • 2016알파고, 바둑을 정복하다

    구글 딥마인드의 알파고가 이세돌 9단과의 대국에서 4승 1패로 승리합니다. 바둑은 경우의 수가 우주의 원자 수보다 많다고 알려져 “기계는 절대 못 이긴다”던 종목이었습니다. 딥블루와 달리 알파고는 딥러닝으로 스스로 패턴을 학습했다는 점에서 질적으로 달랐습니다.

  • 2017트랜스포머, 지금 LLM의 씨앗

    구글 연구진이 〈Attention Is All You Need〉 논문에서 트랜스포머(Transformer) 구조를 발표합니다. 단어를 앞에서부터 하나씩 읽던 방식에서, 글의 맥락을 통째로 보고 관련도를 계산하는 방식으로 바뀌면서 훨씬 많은 데이터를 빠르게 학습하게 됐습니다. 오늘날 거대 언어 모델(LLM)의 설계도이고, ‘GPT’의 T가 바로 Transformer입니다.

  • 2022말로 AI를 쓰는 시대

    Midjourney와 ChatGPT가 공개됩니다. “와, 얘랑 진짜 말이 통하네?” 하는 충격이 전 세계로 번졌고, ChatGPT는 출시 두 달 만에 사용자 1억 명을 넘기며 역사상 가장 빠르게 퍼진 서비스가 됩니다. 누구나 말로 AI에게 글과 그림을 시키게 된 겁니다.

  • 2023–지금글·이미지·영상을 함께

    글과 이미지, 음성, 영상을 한 번에 다루는 AI가 나오고, Kling 같은 영상 생성 AI도 등장합니다. 도구를 써서 직접 일을 처리하는 AI 에이전트도 나왔는데, 이건 AI Agent 과정에서 이어서 다룹니다.

한 줄 요약

생각하는 기계를 꿈꿨고 → 딥러닝·트랜스포머로 똑똑해졌고 → 챗봇으로 누구나 쓰게 됐습니다. 그 사이 바뀐 건 AI를 쓰는 방법이 "말"이 됐다는 것. 그래서 말하는 기술, 프롬프트가 중요해졌습니다.

2AI · 머신러닝 · 딥러닝 · 생성형 AI

네 단어는 따로 있는 게 아니라 큰 원 안에 작은 원이 들어 있는 관계입니다. 예전에는 "고양이는 귀가 뾰족하고…"처럼 사람이 특징을 알려 줘야 했다면, 딥러닝은 고양이 사진을 아주 많이 보고 무엇이 고양이다운지 스스로 알아냅니다.

인공지능 AI

사람의 지능으로 하던 일을 컴퓨터가 하게 만드는 기술 전체

예: 음성 비서 (시리·빅스비) · 자율 주행 자동차
머신러닝 Machine Learning

규칙을 일일이 가르치지 않고, 많은 예제를 보고 스스로 패턴을 찾는 방법

예: 스팸 메일 거르기 · 넷플릭스 추천
딥러닝 Deep Learning

뇌의 신경망을 흉내 낸 여러 층의 구조로, 무엇을 봐야 할지(특징)까지 스스로 찾아내는 머신러닝

예: 스마트폰 얼굴 인식 · 사진 속 고양이 찾기
생성형 AI Generative AI

딥러닝을 바탕으로, 명령어(프롬프트)에 따라 새로운 글·그림·영상을 만들어 내는 AI

예: ChatGPT (글) · Midjourney·Kling (이미지·영상)

3AI가 배우는 세 가지 방식

우리가 매일 쓰는 서비스 안에 이미 다 들어 있습니다.

방식비유이미 쓰고 있는 곳
지도학습 (Supervised)앞면엔 문제, 뒷면엔 정답이 적힌 카드로 공부. 정답은 사람이 붙여 줌스팸 메일함 - 스팸 / 정상
사진첩 인물 분류 - 엄마 / 친구 / 나
오늘 실습 A - 정답을 직접 학습
비지도학습 (Unsupervised)정답 없이 섞인 단추를 비슷한 것끼리 모으기. 이름은 다 모은 뒤 사람이 붙임쇼핑몰 고객 그룹 - 구매 기록만으로 저절로 무리 지어짐
포털의 '관련 기사 묶음' - 내용이 비슷한 기사끼리 한 묶음
강화학습 (Reinforcement)잘하면 점수, 못하면 감점 받으며 스스로 터득알파고, 게임 AI, 자율 주행

4내 손으로 AI 학습시키기

실습 A — Teachable Machine으로 고양이·강아지 구분 AI 만들기
준비물①실습A_학습용_테스트용이미지.zip

구글의 무료 도구로 고양이·강아지를 구분하는 AI를 직접 만듭니다. 정답(이름표)을 붙인 사진을 주고 배우게 하니 지도학습이고, 속은 딥러닝 이미지 모델입니다.

단계뜻실습 A에서
① 데이터 모으기배울 예제를 모은다이미지 폴더 다운로드
② 정답 붙이기예제마다 이름표를 단다클래스 이름 cat / dog
③ 학습 → 모델예제를 반복해 보며 규칙을 찾는다. 그 결과물이 모델모델 학습시키기
④ 처음 보는 것에 답하기배운 적 없는 예제에 확률(%)로 답한다test 폴더 사진으로 미리보기

시험 문제를 공부한 문제집에서 내면 늘 맞히겠죠. 그래서 확인용 사진(test)은 학습용 사진(train)과 따로 둡니다.

  1. Teachable Machine 페이지 — teachablemachine.withgoogle.com → 시작하기(Get Started) → 이미지 프로젝트(Image Project) → 표준 이미지 모델(Standard image model)
  2. 이미지 다운로드 — 실습A_학습용_테스트용이미지.zip을 받아 압축을 풉니다. 안에 train/cat · train/dog · test 폴더가 있습니다.
  3. 클래스(Class) — Class 1을 cat, Class 2를 dog로 이름 변경 → 업로드(Upload)로 각 폴더 사진을 끌어다 놓기
  4. 학습(Training) — 고급(Advanced)을 열어 세 값을 확인만 하고, 기본값 그대로 모델 학습시키기(Train Model). 학습 중에는 탭을 옮기지 않습니다.
    학습 설정뜻공부에 비유하면기본값
    에포크 (Epochs)전체 사진을 처음부터 끝까지 몇 번 반복해서 볼지문제집 몇 회독50
    배치 크기 (Batch Size)한 번에 몇 장씩 묶어서 보고 고칠지몇 문제 풀고 채점할지16
    학습률 (Learning Rate)틀렸을 때 생각을 얼마나 크게 고칠지오답 보고 공부법을 얼마나 바꿀지0.001

    이렇게 사람이 정하는 학습 설정을 하이퍼파라미터라고 합니다. 시간이 남으면 에포크를 5로 줄여 다시 학습해 보세요. 확률이 덜 확실하게 나오거나 틀리는 사진이 늘 수 있습니다 — 공부를 덜 시키면 덜 똑똑합니다.

  5. 미리보기(Preview) — 입력(Input)을 파일(File)로 바꾸고 test 폴더 사진을 하나씩 넣어 출력(Output) 막대를 봅니다. AI는 정말 "고양이"를 배웠을까요?
    테스트 사진AI의 답왜 그럴까
    실내 고양이 · 잔디 강아지잘 맞힘배운 사진과 비슷하니까
    잔디 위 고양이강아지라고 틀림동물이 아니라 배경으로 구분하고 있었다 (학습용 고양이는 전부 실내, 강아지는 전부 잔디)
    실내 강아지고양이라고 틀림같은 이유 — 실내면 고양이라고 배웠다
    여우cat이나 dog 중 하나로 자신 있게 틀림cat·dog 말고는 모르는데, "모르겠다"고 하지 않는다

    AI는 내가 준 예제만큼 압니다. 그리고 우리가 의도한 걸 배웠다는 보장도 없습니다. 고치려면? 잔디 위 고양이, 실내 강아지 사진을 더 넣고 다시 학습하면 됩니다 — 데이터를 고치면 AI가 바뀝니다.

  6. 모델 내보내기(Export Model) — Tensorflow.js 탭 → 업로드(Upload my model) → 생성된 공유 가능한 링크(Shareable link) 복사 → 옆 사람에게 보내 써 보게 하기. 이 링크는 실습 B에서 다시 씁니다.
    ※ 업로드는 영문 페이지에서 진행하세요. 한국어 화면에서는 업로드가 안 될 수 있습니다.
할루시네이션

여우를 cat이나 dog라고 우기던 모델처럼, AI가 모르는 것도 모른다고 하지 않고 자신 있게 틀리는 현상을 할루시네이션(환각)이라고 합니다. 생성형 AI에서는 사실이 아니거나 근거 없는 내용을 사실처럼 말하는 모습으로 나타나고, 학습 데이터가 부족하거나, 질문이 모호하거나, 최신 정보를 확인 없이 답할 때 생깁니다. 그래서 질문은 구체적으로, 중요한 내용은 확인하는 습관이 필요합니다.

5생성형 AI의 종류 — 왜 이 세 가지일까?

생성형 AI는 만드는 결과물에 따라 나뉩니다. 글, 이미지, 영상, 음성 등이 있고, 분야마다 여러 도구가 있습니다.

이미지설명으로 그림 만들기, 스타일 변환, 캐릭터·포스터Midjourney, ChatGPT 이미지, Firefly

이 수업에서는 하나의 아이디어를 글 → 이미지 → 영상으로 키워 가는 흐름을 배웁니다. 그래서 위 표에서 분야마다 대표 도구를 하나씩 골랐습니다.

그중 ChatGPT — 글을 맡은 도구

GPT라는 이름

GPT는 Generative Pre-trained Transformer의 줄임말입니다. 글을 만들어 내고(Generative), 엄청난 글을 미리 읽고 배웠고(Pre-trained — 아래 '어떻게 배웠나'의 미리 학습), 1번 타임라인 2017년의 트랜스포머 구조로 만든(Transformer) 모델이라는 뜻입니다. 앞에 붙은 Chat은 말 그대로 채팅, 대화로 쓰는 GPT라는 뜻입니다.

누가 만들었나 — OpenAI

ChatGPT는 미국의 OpenAI가 만들었습니다. 2015년 샌프란시스코에서 "AI가 인류 전체에 도움이 되게 하자"는 목표의 비영리 연구소로 출발했고, 샘 올트먼(Sam Altman)이 CEO를 맡고 있습니다. 이후 마이크로소프트의 대규모 투자를 받으며 회사 규모로 커졌고, 2022년 11월 ChatGPT를 공개해 1번 타임라인의 "말로 AI를 쓰는 시대"를 열었습니다.

어떻게 배웠나

ChatGPT는 어떻게 이렇게 말을 잘하게 됐을까요? 3번에서 본 세 가지 방식을 모두 거쳤습니다.

단계하는 일3번의 어떤 방식?
① 미리 학습인터넷의 엄청난 양의 글을 읽으며 "다음에 올 말"을 맞히는 연습을 반복정답을 따로 붙이지 않고 글 자체에서 스스로 배움 (비지도에 가까움)
② 대화 연습사람이 만든 좋은 질문·답변 예시로 대화하는 법을 배움지도학습
③ 다듬기여러 답 중 사람이 더 좋다고 고른 쪽으로 점점 맞춰 감강화학습

세 가지 방식이 ChatGPT 하나에 다 들어 있습니다. 그리고 답할 때는 가장 그럴듯한 다음 말을 하나씩 이어 붙입니다. 그래서 같은 질문에도 매번 답이 조금씩 다르고, 앞에서 본 할루시네이션처럼 그럴듯하게 틀릴 수 있습니다.

6글을 만드는 AI vs 그림·영상을 만드는 AI

세 도구 모두 프롬프트(글)로 지시한다는 점은 같지만, 결과를 만드는 방식이 다릅니다.

LLM (대형 언어 모델) → ChatGPT

아주 많은 글을 학습해서, 다음에 올 말을 예측하며 문장을 이어 씁니다.

이미지 · 영상 생성 모델 → Midjourney, Kling

흐릿한 노이즈에서 시작해 프롬프트에 맞게 조금씩 그림을 다듬어 갑니다. 영상은 이 과정을 여러 장면으로 이어 붙인 것입니다.

LLM은 ChatGPT에만 해당

Midjourney와 Kling은 말을 알아듣는 부분은 있지만, 글이 아니라 그림·영상을 만드는 AI입니다.

7AI의 사용량 단위 — 토큰 · GPU 시간 · 크레딧

AI는 쓴 만큼 비용이 드는 도구이고, 도구마다 사용량을 세는 단위가 다릅니다.

토큰 (ChatGPT) — LLM은 글을 토큰이라는 작은 조각으로 쪼개서 읽고 씁니다. 대화가 길어질수록 토큰이 쌓이고, 너무 길어지면 앞 내용을 잊어버리기도 합니다.

사용량 — 얼마나 쓸 수 있나

요금제마다 쓸 수 있는 양이 정해져 있습니다. (2026년 11월 공식 안내 기준)

  • 일반 대화 — 무료를 포함한 모든 요금제에서 사실상 무제한 (지나친 남용만 막음)
  • 기능별 한도 — 파일 올리기, 이미지 생성, 심층 리서치, 음성 대화, 생각하는 모델은 따로 한도가 있습니다. 예: 무료는 파일 업로드 하루 3개
  • 시간 단위로 초기화 — Plus는 무거운 작업 기능에 5시간 단위와 1주 단위 한도가 함께 걸려 있고, 첫 사용 시점부터 시간이 셉니다
  • 한도에 닿으면 — 다른 모델로 이어서 쓰거나, 초기화 시간까지 기다리면 됩니다
  • 내 사용량 확인 — 설정 → 사용량(Usage)에서 남은 양과 초기화 시간을 볼 수 있습니다

구독과 API — API가 무서운 이유

  • 구독은 사용량이 정해져 있어, 구독한 금액만큼만 씁니다. 한도에 닿으면 기다리거나 다른 모델로 넘어갈 뿐 돈이 더 나가지 않습니다.
  • API는 토큰 단위로 돈을 받습니다. 글을 많이 주고받을수록 토큰이 쌓이고 그만큼 청구됩니다. 문제는 "얼마 나올지 미리 가늠하기 어렵다"는 점. 그래서 개발 지식 없이 API를 만지면 요금 폭탄을 맞기 쉽습니다.
구독

사람이 채팅 앱에서 쓰는 용도 + 정액 요금 + 사용 한도. 사람이 직접 채팅하는 용도입니다.

API

개발자가 프로그램에 붙여 쓰는 용도 + 종량 요금 + 한도 없이 쓴 만큼 청구. 프로그램이 자동으로 호출하는 용도입니다.

ChatGPT의 API는 platform.openai.com에서 따로 가입·충전합니다. 같은 계정이어도 결제는 별개라, ChatGPT를 구독해도 API 사용량은 포함되지 않습니다.

AI가 한 대화에서 기억할 수 있는 길이도 토큰으로 정해집니다 — 대화가 아주 길어지면 앞부분을 잊는 이유입니다. 이 과정은 구독만 씁니다.

숫자와 한도는 자주 바뀌니, 정확한 값은 공식 도움말과 내 계정의 사용량 화면에서 확인하세요.

9AI가 아직 약한 것

오늘 겪은 것들을 모아 보면, AI가 왜 틀리는지가 보입니다.

약한 것왜 그런가어떻게 대처하나
모르는 것도 자신 있게 말함4번 실습의 여우 — 할루시네이션중요한 내용은 직접 확인
배운 것만 안다 (편향)4번 실습에서 고양이를 배경으로 구분한 것처럼, 학습 데이터가 치우치면 답도 치우침결과를 한쪽 시각으로만 보지 않기

오늘의 결론

AI는 똑똑하지만 내가 말해 준 만큼만 압니다. 그래서 정확히 말하고, 결과는 확인한다 — 이 과정에서 12차시 동안 연습할 것입니다.

오늘 세 도구로 만든 글, 이미지, 영상은 마음에 쏙 들었나요? AI는 똑똑하지만, 무엇을 원하는지 정확히 말해 주지 않으면 평범하거나 엉뚱한 결과를 냅니다. 다음 시간에는 오늘 결과를 돌아보고, 아쉬운 부분을 프롬프트 기본 구조로 고쳐 봅니다.
