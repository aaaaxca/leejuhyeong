AI Agent 1 · 11차시

이미지 만들기

어디서 본 듯한 그림, 마음대로 들어간 소품, 매번 달라지는 결과 — 문제는 AI가 아니라 내 지시입니다. 벤치마크 3장으로 도구를 재고, 6요소로 이미지 프롬프트를 Claude에게 뽑게 한 뒤, 생성 → 비평 → 재생성 루프로 다듬고, 글자와 레이아웃은 Claude의 디자인 캔버스에서 마감합니다.

Claude (PC)이미지 생성 도구 (ChatGPT · Gemini 등)레퍼런스 이미지 1장 (각자 준비)
1도구와 약점2벤치마크36요소4프롬프트 뽑기5비평 루프6카드뉴스7사고 지점8글자 · 레이아웃9정리
오늘의 가상 상황

그린컵이 다음 주에 신제품 데일리 텀블러를 올립니다. 필요한 건 상세페이지 배너 1장, SNS 카드뉴스 5장, 사내 공지 포스터 1장. 외주는 2주 뒤에나 된답니다. 이미지 AI에 "텀블러 홍보 이미지 그려 줘"라고 넣어 보니 예쁘긴 한데 어디서 본 듯하고, 카피 넣을 자리가 없고, 브랜드 색과 안 맞습니다. 다시 넣으면 매번 다르게 나옵니다.

1. 이미지 도구와 자주 틀리는 곳

실력 순위는 몇 달마다 바뀝니다. 이름보다 강점의 종류를 기억하세요.

도구강한 지점이럴 때
ChatGPT 이미지지시를 정확히 따름, 글자 · 배치, 대화로 고치기배너 · 썸네일 · 포스터처럼 지시가 복잡할 때
Gemini (나노 바나나)사진 편집 · 합성, 실사 느낌, 같은 인물 유지"이 제품 사진 배경만 바꿔 줘"
Midjourney예술적 완성도 · 분위기무드컷, 브랜드 비주얼 (유료 전용)
Ideogram타이포그래피글자가 주인공인 이미지
Adobe FireflyAdobe 도구와 연결, 상업적 사용 조건이 명확회사에서 Adobe를 이미 쓸 때

Claude에는 사진 같은 이미지를 만드는 기능이 없습니다. 대신 세 가지를 합니다. 내 의도를 이미지 AI가 알아듣는 문장으로 옮기는 프롬프트 설계, 나온 이미지를 보고 지시와 다른 곳을 짚는 비평, 포스터 · 카드뉴스의 글자와 레이아웃. 그래서 오늘의 흐름은 Claude로 프롬프트 → 이미지 도구로 생성 → Claude로 비평 · 마감입니다.

시험 문제왜 어려운가
손 클로즈업손가락 개수 · 관절이 자주 무너짐
간판에 한글 쓰기많이 좋아졌지만 긴 문장 · 작은 글씨는 아직 받침이 틀리기도 함
"가득 찬 와인잔"세상의 와인잔 사진 대부분이 반쯤 차 있어서 그쪽으로 끌림
"3시 15분을 가리키는 시계"시계 광고 사진이 대부분 10시 10분
"사람 4명, 각자 다른 색 옷"요소가 늘수록 하나씩 빠지거나 섞임

공통점이 보이나요? 실패는 전부 세상에 흔한 쪽으로 미끄러지는 것입니다. 지시가 애매하면 가장 흔한 답을 그립니다. 흔하지 않은 걸 원하면 그만큼 더 구체적으로 말해야 합니다. 02차시 원칙이 그림에서도 똑같이 작동합니다.

2. 나만의 벤치마크 3장

1등 모델이 내 업무에서도 1등이라는 보장은 없습니다. 고정 프롬프트 3개로 내 그림에서 재 봅니다.

새 AI 모델이 나오면 사람들이 가장 먼저 시켜 보는 게 "펠리컨이 자전거를 타는 그림을 SVG 코드로 그려 줘"입니다. 생김새와 구조를 알고 말이 되게 조립하는 능력을 보는 비공식 시험이죠. 이렇게 정해 두고 반복하는 시험 문제를 벤치마크라고 합니다. 내 업무에도 하나 만들어 둡니다.

실습 A — 벤치마크 3장 돌리고 채점

이미지 생성 도구(ChatGPT 등)의 새 대화에서 하나씩 붙여 넣습니다. 가능하면 2~3번씩 돌려 보고 판단합니다.

1 · 제품컷 (주력 컷)
실사 제품 사진. 나무 테이블 위에 놓인 흰색 머그컵 하나, 김이 살짝 오른다.
정면에서 살짝 위로 본 각도, 머그컵이 화면 중앙.
아침 자연광, 따뜻한 톤. 차분하고 깔끔한 느낌.
비율 1:1. 글자·로고는 넣지 않는다.
2 · 사람이 들어간 장면 (손 · 얼굴 확인용)
플랫 벡터 일러스트. 사무실 책상에서 노트북을 보며 웃고 있는 30대 직장인, 한 손은 키보드 위. 인물은 화면 왼쪽, 상반신.
밝은 오후 조명, 파랑·흰색 위주. 활기차고 편안한 분위기.
비율 4:5. 실존 인물과 닮은 얼굴은 넣지 않는다.
3 · 한글 글자 (도구별 차이가 가장 큰 곳)
행사 안내 배너. 왼쪽에 선물 상자 그림, 오른쪽에 굵은 한글 제목 "가을 감사 이벤트"와 그 아래 작은 글씨 "10월 31일까지".
연한 베이지 배경, 깔끔한 고딕체. 밝고 단정한 느낌.
비율 16:9. 제목 외 다른 글자는 넣지 않는다.

채점 — 지시를 그대로 따랐나 · 구도 · 비율이 맞나 · 손 · 얼굴이 정상인가 · 한글이 안 깨졌나를 ○ / △ / 로 적고, "이 도구가 잘하는 것 / 약점" 두 줄로 정리합니다. 이 프롬프트 3개는 버리지 마세요. 새 도구가 나오면 그대로 넣어 비교합니다.

3. 이미지 프롬프트 6요소

칸을 비워 두면 AI가 안 정하는 게 아니라 가장 흔한 것으로 정합니다.

요소질문벤치마크 1번에서
① 주제 · 동작누가 / 무엇이 뭘 하나나무 테이블 위 흰색 머그컵, 김이 살짝
② 구도 · 앵글어디서, 얼마나 가까이, 여백은정면에서 살짝 위, 화면 중앙
③ 스타일 · 매체사진인가 그림인가실사 제품 사진
④ 조명 · 색밝기 · 색감아침 자연광, 따뜻한 톤
⑤ 분위기어떤 느낌차분하고 깔끔한
⑥ 용도 · 비율 · 금지어디 쓰나, 비율, 넣지 않을 것1:1, 글자 · 로고 금지
쓸 때 주의어떻게
가장 자주 비는 칸④ 조명 · 색, ⑤ 분위기. 결과가 밋밋하면 여기부터 채우기
스타일은 단어 하나가 제일 셈실사 제품 사진 / 플랫 벡터 / 수채화 / 3D 렌더링 / 아이소메트릭
비율은 먼저 정함나중에 자르면 구도가 망가짐. 배너 16:9, 인스타 1:1 · 4:5, 포스터 3:4, 스토리 9:16
넣지 않을 것ChatGPT · Gemini엔 따로 칸이 없으니 "○○, ○○은 넣지 않는다." 한 문장으로 끝에 붙이기
글자는 나중에 얹기고칠 일이 있거나 여러 장이면 배경만 뽑고, 글자는 8절에서 얹기
자주 쓰는 넣지 않을 것 문장
이미지 안의 글자·로고·워터마크, 손 클로즈업, 과장된 스톡사진 표정, 특정 브랜드 상표, 실존 인물과 닮은 얼굴, 프레임·테두리, 형광색은 넣지 않는다.

4. 오늘의 핵심 — Claude로 이미지 프롬프트 뽑기

6요소를 매번 손으로 채우는 건 그림 작업이 아니라 글쓰기 작업입니다. 글쓰기는 Claude가 잘합니다.

실습 B — 보통 쓰는 지시로 먼저

이미지 도구에 "텀블러 홍보 이미지 그려 줘" 한 줄만 넣습니다. 결과를 저장해 두세요. 실습 D에서 비교합니다.

실습 C — Claude에게 프롬프트 뽑게 하기

Claude의 새 대화에 그대로 붙여 넣습니다.

아트 디렉터 지시문
너는 숙련된 아트 디렉터야. 나는 이미지 생성 AI에 넣을 프롬프트가 필요해.
[용도] 그린컵 신제품 상세페이지 상단 배너
[제품] 민트색 스테인리스 텀블러 (350ml, 친환경 컨셉)
[보는 사람] 20~40대, 환경에 관심 있는 직장인
[느낌] 조용하고 단정한 일상. 과장된 광고 느낌은 피하고 싶음
[꼭 들어갈 것] 텀블러가 주인공, 자연광
[피할 것] 손 클로즈업, 이미지 안 글자, 형광색, 특정 브랜드 로고
[비율] 16:9, 오른쪽 1/3은 카피가 들어갈 여백
다음을 해 줘:
1. 서로 확실히 다른 컨셉 3안을 한 줄씩 제안하고, 각각의 장단점을 알려 줘.
2. 내가 하나를 고르면, 그 컨셉으로 6요소(주제·동작 / 구도·앵글 / 스타일·매체 / 조명·색 / 분위기 / 비율·금지사항)를 모두 채워 한 문단으로 써 줘.
3. 같은 내용의 영어 버전도 함께 줘.
4. 넣지 않을 것은 "○○, ○○은 넣지 않는다." 한 문장으로 따로.
  1. 3안 비교하고 고르기 — 바로 프롬프트를 달라고 하면 첫 번째로 떠오른 뻔한 안이 나옵니다. 3안을 비교하고 고치는 순간 여러분이 디렉터가 됩니다.
  2. 구도 · 스타일 고치기 — 정하기 어려운 두 칸을 읽고 원하는 대로 바꿉니다. 예: "구도는 정면에서 바라보는 각도로, 스타일은 따뜻한 수채화 느낌으로 바꿔 줘."
  3. 6요소 검수 — "방금 쓴 프롬프트가 여섯 칸을 모두 채웠는지 표로 점검하고, 빠지거나 흐릿한 칸이 있으면 채워서 다시 써 줘."

ChatGPT · Gemini는 한국어로 넣어도 충분합니다. 영어 버전은 Midjourney처럼 영어가 더 잘 통하는 도구를 쓰거나, 결과가 지시와 다를 때 바꿔 넣어 보는 용도입니다. 이미지 안에 넣을 한글 글자는 번역하지 마세요.

5. 생성 → 비평 → 재생성

Claude는 이미지를 만들지는 못해도 보고 판단합니다. "왜 이상한지 모르겠는데 이상한" 상태를 말로 풀어 줍니다.

실습 D — 비평 루프
  1. 2장 뽑기 — 실습 C 프롬프트를 이미지 도구에 넣어 1장, "같은 프롬프트로 한 장 더"로 1장. 나은 것을 고릅니다. 한 장만 보면 운이 나빴던 건지 알 수 없습니다.
  2. 비평 받기 — 고른 이미지를 실습 C의 Claude 대화에 첨부하고:
    비평
    방금 만든 이미지를 첨부할게. 위에서 쓴 프롬프트와 비교해서 다른 점을 짚어 줘.
그중 가장 중요한 한 가지만 고친 프롬프트 전체를 한국어로, 이미지 도구에 바로 붙여 넣을 수 있게 코드 블록으로 줘.
  3. 빠진 건 내가 덧붙이기 — 예: "색은 민트(#79C7B0 계열)로 바꾼 프롬프트를 다시 만들어 줘." #79C7B0 같은 색상 코드는 색을 정확히 가리키는 번호입니다. 브랜드 색이 있으면 그 코드를 씁니다
  4. 다시 만들기 — 원하는 대로 나올 때까지 2~3회. 조명 · 구도 · 색을 한꺼번에 바꾸면 뭐가 효과였는지 모르니 한 번에 한두 가지씩.
  5. 실습 B와 비교 — 실습 B → 1차 → 최종본을 나란히 놓습니다. 더 예쁜가가 아니라 카피 자리 · 소품 · 빛 방향이 내가 정한 대로 나왔는지 봅니다.
이런 게 보이면이렇게 바꿔 보기
앵글이 안 바뀜"책상 높이 눈높이에서 정면으로"처럼 앵글 문장을 맨 앞으로
색이 원하는 색이 아님색상 코드로 구체적으로
제품이 원하는 위치에 없음"화면 왼쪽 1/3"처럼 위치를 문장 앞쪽으로
비워 둔 카피 자리에 뭔가 그려짐"오른쪽 1/3은 비운다"를 앞쪽으로 옮겨 강조

"AI가 알아서 그린 그림"과 "내가 정한 그림"은 다릅니다. 차이를 만드는 건 도구가 아니라 지시입니다. 잘 된 프롬프트는 Project에 모아 두고, 파일은 배너_v1_자연광, 배너_v2_역광처럼 버전을 남기세요.

6. 스타일 역추출 — 카드뉴스 5장

5장이 제각각이면 아마추어처럼 보입니다. 레퍼런스로 느낌을 정하고 5장을 한 번에 시킵니다.

실습 E — 레퍼런스에서 공통 규칙 뽑기

원하는 느낌의 카드뉴스를 하나 캡처합니다(인스타 #카드뉴스, 핀터레스트). 남의 이미지는 느낌만 참고하고 그대로 쓰지 않습니다. 시간이 없으면 실습 D의 최종 이미지를 써도 됩니다. 내가 만든 거라 가장 안전합니다.

역추출
이 이미지를 참고해서 비슷한 느낌의 카드뉴스 5장을 만들고 싶어.
스타일·조명·구도·색감을 분석하고, 그대로 베끼지 말고 스타일 방향만 가져와 줘.
공통 규칙을 먼저 한 덩어리로 적고, 그 뒤에 장별 차이만 적는 형식으로.
주제: 1) 제품 소개 2) 보온 성능 3) 세척 편의 4) 친환경 소재 5) 구매 안내
마지막에 공통 규칙 + 장별 장면 + 넣지 않을 것 문장을 합친 완성 프롬프트 5개를, 장마다 각각 코드 블록으로 줘.

이어서 "위 카드뉴스 5장에 들어갈 제목과 짧은 문구를 장마다 써 줘. 그린컵 말투로, 제목은 15자 이내, 문구는 한두 줄로." — 문구는 8절에서 얹습니다.

조절 구간 — 빠른 수강생은 "이 배너 프롬프트를 인스타(1:1)용과 스토리(9:16)용으로 각각 바꿔 줘. 비율이 바뀌면 구도도 어떻게 바뀌어야 하는지 반영해서." 텀블러 위치와 카피 자리가 어떻게 달라지는지 봅니다.

7. 실무에서 사고 나는 지점

이미지는 밖으로 나가는 결과물이라 글보다 위험합니다.
