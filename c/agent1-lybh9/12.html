AI Agent 1 · 12차시

아티팩트 · 배포

"텀블러 120개에 로고 넣으면 얼마예요?" 하루 다섯 번 오는 같은 계산을, 말로 만든 도구로 끝냅니다. 규칙 문서를 붙이고 → 뼈대부터 → 하나씩 → 숫자로 검산하는 순서로 견적 계산기를 만들고, 링크로 팀에 넘긴 뒤, Claude 계정이 없는 사람도 여는 웹 주소로 배포하는 데까지 갑니다.

오늘의 가상 상황

그린컵 영업팀에 단체주문 문의가 옵니다. 견적 규칙 문서를 열고, 엑셀을 켜고, 기본가 × 수량, 옵션 더하고, 수량 할인 8% 빼고, 재구매 3% 더 빼고, 배송비, 부가세… 10분. 이게 하루 다섯 번입니다. 신입이 계산하면 할인을 두 개 겹쳐 적용해서 자꾸 틀립니다. 오늘 코드 한 줄 안 쓰고, 팀원에게 링크로 넘길 수 있는 계산기를 만듭니다.

1. 아티팩트 — 답이 아니라 물건

대화 중에 오간 말이 아니라, 따로 만들어져 남는 결과물입니다.

대화로 받으면아티팩트로 받으면
받는 것계산된 답 하나계산기 자체
다음에 또 필요하면다시 물어본다그냥 쓴다
팀원이 쓰려면나를 거쳐야 함링크를 준다
대화를 닫으면대화 속에 묻힘사이드바 '아티팩트'에 모임
고치려면처음부터 다시"여기만 바꿔 줘"

계산기 · 입력 양식 · 체크리스트 · 대시보드 같은 반응하는 도구가 오늘의 주인공입니다. 문서 · 슬라이드 · 디자인도 아티팩트로 만들 수 있고, 05 · 11차시에서 받은 파일과 포스터도 같은 곳에 모입니다.

실습 A — 5분 맛보기: 회의 비용 계산기
붙여 넣기
회의 시간 비용 계산기를 만들어 줘.
- 참석자 수, 회의 시간(분), 평균 시급을 입력하면 이 회의에 든 인건비가 나오게
- 숫자를 바꾸면 결과가 바로 바뀌게
- 결과 밑에 '이 회의를 30분 줄이면 얼마가 절약되는지'도 같이 보여 줘

확인할 것 — 대화 옆에 실제로 동작하는 계산기가 열리나요? 8명 · 60분 · 시급 30,000원이면 240,000원, 30분 줄이면 120,000원 절약. 직접 곱해서 맞는지 보세요. 오늘 내내 할 검산의 첫 연습입니다. 글로만 나왔다면 "이걸 아티팩트로 만들어 줘"라고 한 번 더 말하고, 그래도 안 되면 설정 → 기능에서 코드 실행 및 파일 생성이 켜져 있는지 확인합니다.

2. 만드는 순서 — 한 번에 완성하려 하지 마세요

규칙을 통째로 붙이고 "다 만들어 줘"라고 하면 뭔가 나오긴 하는데, 어디가 틀렸는지 알 수 없습니다.

단계무엇왜
① 규칙을 붙인다계산 규칙 문서를 그대로 첨부말로 옮기면 반드시 빠뜨림
② 뼈대만 만든다기본가 × 수량만 되는 계산기여기가 맞아야 나머지가 의미 있음
③ 하나씩 붙인다옵션 → 수량 할인 → 추가 할인 → 배송 → 부가세틀리면 범인은 항상 방금 붙인 것
④ 숫자로 검산한다손으로 낸 견적과 대조화면이 예쁘다고 맞는 게 아님
고칠 때 나쁜 요청좋은 요청
"좀 이상한데 다시 만들어 줘""수량 할인이 옵션 금액을 빼고 계산되고 있어. 옵션 포함 소계에 적용되게 고쳐 줘"
"더 예쁘게""입력칸을 왼쪽, 결과를 오른쪽에 두고, 최종 금액만 크게"
"기능 더 넣어 줘""제주·도서산간 체크박스를 추가하고, 체크하면 배송비에 25,000원 더해 줘"

고칠 땐 아티팩트를 만든 그 대화에 이어서 말합니다. 새 대화를 열면 Claude가 그 도구를 모릅니다. 망가지면 "방금 바꾼 것 취소하고 그 전 상태로 돌려 줘"라고 하거나, 고치기 전 내 메시지를 편집해 다시 보내 대화를 갈라 만들면 됩니다. 그러니 과감하게 고쳐도 됩니다.

3. 견적 계산기 — 오늘의 본편

규칙 문서 하나를 팀원이 쓸 수 있는 도구로 바꿉니다.

실습 B — 뼈대와 경계값

새 대화를 열고 대화 이름을 '12차시 견적 계산기'로 바꿔 둡니다. quote_rules.docx(규칙 7개 항목)를 첨부합니다.

뼈대만
이 견적 규칙 문서를 읽고, 단체주문 견적 계산기를 만들려고 해.
지금은 1번(기본 단가)과 3번(수량 할인)만 반영해 줘. 나머지는 나중에 붙일 거야.
제품을 고르고 수량을 넣으면 소계와 할인이 적용된 금액이 나오게. 숫자를 바꾸면 바로 반영되게.

경계값 넣어 보기 — 수량에 20, 99, 100을 차례로. 제품 4종(베이직 350 · 500ml / 보온병 500 · 750ml), 할인 4단계(50 · 100 · 300 · 500), 100개에서 8%인지 봅니다. 규칙은 "100개 이상 8%"입니다. AI가 '초과'로 만들면 딱 100개만 5%로 나오고, 99나 101에선 티가 안 납니다. 구간이 바뀌는 바로 그 숫자를 꼭 직접 넣어 보세요.

실습 C — 규칙 하나씩 붙이기

하나 보내고 → 숫자 확인하고 → 다음 것.

  1. 옵션 — "2번 옵션을 추가해 줘. 로고 인쇄(단색/풀컬러), 개인 각인, 선물 포장을 체크박스로. 옵션은 개당 금액이야." 옵션을 켜면 금액이 수량만큼 늘어나나
  2. 할인 기준 확인 ← 핵심 — "수량 할인이 옵션 금액을 포함한 소계에 적용되고 있는지 확인해 줘. 규칙 문서 3번 아래 주석을 봐." 옵션을 켜면 할인액도 같이 커지나. 규칙 문서 7번 '자주 나오는 실수'에 적혀 있는 바로 그 실수입니다. 사람도 틀리는 걸 AI도 틀립니다
  3. 추가 할인 — "4번 추가 할인을 넣어 줘. 재구매·공공기관·신규 거래처 세 가지인데 중복 적용이 안 돼. 둘 이상 해당하면 고객에게 유리한 쪽 하나만. 어느 게 적용됐는지도 화면에 보여 줘." 셋 다 체크하면 하나만 적용되나
  4. 배송비 — "5번 배송비를 넣어 줘. 100만원 기준으로 갈리고, 제주·도서산간은 체크박스로 25,000원 추가야." 100만원 정확히에서 무료인가
  5. 마무리 규칙 — "6번 규칙을 넣어 줘. 최소 주문 20개 미만이면 견적이 안 나오고 안내 문구가 뜨게. 부가세 10%는 별도로 더하고, 배송비에도 부가세가 붙어. 최종 금액은 10원 단위에서 버림." 배송비에도 부가세가 붙나, 19개에서 막히나

4. 검산 — 셋 다 맞을 때까지가 완성

아티팩트는 결과가 너무 그럴듯하게 나옵니다. 그럴듯함이 정확함은 아닙니다.

실습 D — 세 케이스 대조
케이스조건정답
① 기본베이직 350ml · 120개 · 로고 단색 · 재구매 · 서울1,903,100원
② 함정보온병 500ml · 50개 · 각인 + 선물포장 · 공공기관이면서 신규 거래처 · 제주1,552,100원
③ 경계베이직 500ml · 19개견적이 안 나와야 함

① 계산 과정 · 15,000 × 120 = 1,800,000 + 옵션 1,200 × 120 = 144,000 → 소계 1,944,000 − 수량 할인 8% 155,520 − 재구매 3% 58,320 = 1,730,160 · 배송비 0 · 부가세 173,016 → 1,903,176 → 10원 단위에서 버림 → 1,903,100

이 숫자가 나왔다면걸린 함정
①에서 1,903,170원"10원 단위에서 버림"을 1원 자리만 버리는 것으로 읽음 — 규칙이 애매하면 AI가 한쪽으로 정해 버립니다. 실무에선 규칙 정한 사람에게 확인
②에서 1,484,300원추가 할인을 둘 다 적용 (공공 5% + 신규 4%) — 67,800원 적게 청구
②에서 1,524,600원제주 배송비를 빼먹음
②에서 1,549,600원배송비에 부가세를 안 붙임
  1. 틀린 곳은 숫자로 짚기 — "이상해요"가 아니라 "120개 케이스에서 수량 할인이 155,520원이어야 하는데 144,000원이 나와. 옵션 금액을 빼고 계산한 것 같아. 옵션 포함 소계 기준으로 고쳐 줘."
  2. 공유 전 점검 — "이 도구에 들어 있는 정보 중, 외부에 공개되면 곤란한 게 있는지 알려 줘."
  3. 사용법 3줄 — "계산기 맨 위에 사용법 3줄을 넣어 줘. 처음 보는 사람이 뭘 고르고 뭘 넣어야 하는지, 그리고 견적 유효기간(14일) 안내까지."

이 도구는 고객에게 나갈 금액을 계산합니다. "대충 맞는 것 같다"로 넘어가지 마세요. 그리고 규칙이 바뀌면 누가 고칠지도 정해 두세요. 안 그러면 6개월 뒤에 낡은 단가로 견적이 나갑니다.

5. 계산 말고도 — 조건 도구 · 데이터 도구

만드는 순서는 같고, 검산하는 방법만 다릅니다.

도구 종류하는 일제일 중요한 확인
계산기규칙대로 숫자를 냄손 계산과 숫자가 같나
체크리스트 생성기조건을 고르면 필요한 항목만 보여 줌나오면 안 되는 항목이 빠졌나
대시보드데이터를 필터로 걸러 보여 줌비교 대상(전체 평균)이 같이 보이나
실습 E — 내 업무 도구 하나

새 대화에서 하나를 골라 만듭니다. 예) 신입 온보딩 체크리스트 — "부서와 입사 형태(정규·계약·인턴)를 고르면 그 사람에게 필요한 항목만 보여 주는 체크리스트를 만들어 줘. 인턴에게는 법인카드 신청 항목이 나오면 안 돼." / 08차시 설문 · 매출 데이터로 대시보드 — "채널을 고르면 그 채널 숫자와 전체 평균이 나란히 보이게."

확인할 것 — 체크리스트는 조건을 바꿔 가며 나오면 안 되는 항목이 숨는지, 대시보드는 필터를 걸어도 비교 기준이 같이 보이는지 봅니다.

기본은 나만 보기입니다. 넘길 때 무엇을 열어 줄지 정합니다.

실습 F — 보기로 공유하고 시험받기

아티팩트 창 오른쪽 위 공유 → 링크가 있는 사용자 → 링크 복사. 이 계산기가 어떻게 돌아가는지 모르는 사람에게 링크를 주고 아무 설명 없이 케이스 ①을 넣어 보게 합니다. 같은 실습을 한 옆 사람은 이미 알아서 시험이 안 됩니다. 막히는 곳이 사용법에 빠진 줄입니다.

AI를 부르는 기능이 들어간 도구를 공유하면, 그 사용량은 쓰는 사람의 계정에서 나갑니다. 회사 정보가 들어간 도구는 공유 범위를 먼저 확인하세요.

7. 배포 — Claude 밖으로 내보내기

Claude 계정이 없는 거래처 · 고객도 주소 하나로 열 수 있게 합니다.

아티팩트를 HTML 파일로 내려받으면 브라우저 어디서나 열립니다. 이걸 인터넷 주소에 올리는 것이 배포입니다. 02차시에서 본 GitHub Pages나, 구글의 Firebase Hosting이 대표적입니다. 명령어가 필요한 부분은 08차시의 Claude Code에게 맡기면 됩니다.

Firebase가 하는 두 가지쓰는 곳
Hosting — 폴더 안의 HTML을 주소로 보여 주기계산기 · 체크리스트 · 대시보드 (저장할 게 없음)
Firestore — 사람들이 입력한 내용 저장하기함께 고치는 회의록처럼 내용이 남아야 하는 도구
실습 G — 오늘 만든 도구를 한 사이트로 배포
  1. 파일 모으기 — 견적 계산기(와 실습 E 도구)를 HTML로 내려받아 바탕화면 내도구사이트 폴더에 넣습니다. 계산기는 calculator.html처럼 알아보기 쉬운 이름으로.
  2. Firebase 프로젝트 만들기 · 사람 — 구글 계정으로 Firebase 콘솔에 들어가 새 프로젝트를 만듭니다. 계정과 결제 화면이 걸린 부분이라 직접 합니다.
  3. Claude Code에 맡기기 — 데스크톱 앱 Code 탭에서 Local · 수동, 폴더는 내도구사이트.
    배포 맡기기
    이 폴더의 HTML 도구들을 하나의 사이트로 묶어서 Firebase Hosting에 배포하려고 해.
① 첫 화면 index.html에 도구 목록과 링크를 만들어 줘
② 내 Firebase 프로젝트 [프로젝트 ID]에 배포해 줘. 필요한 프로그램이 없으면 설치부터 안내해 줘
③ 나는 비개발자니까 명령을 실행하기 전에 무엇을 하는지 한 줄씩 설명해 줘
④ 끝나면 접속 주소를 알려 줘. 시작 전에 계획을 먼저 보여 줘.
  4. 확인 — 휴대폰으로 주소를 열어 케이스 ①을 다시 넣어 봅니다. 배포한 뒤에도 1,903,100원이 나오나요?
Firestore를 쓴다면 — 테스트 모드는 30일 뒤 막힙니다

테스트 모드 규칙은 "이 날짜 전까지 누구나 읽기 · 쓰기"입니다. 날짜가 지나면 페이지는 열려도 불러오기 · 저장이 막힙니다. 누구나 쓸 수 있게 열어 두면 모르는 사람이 내용을 지우거나 고칠 수 있으니, 실제 업무 내용을 넣을 거라면 로그인한 사람만 쓰기로 바꿔야 합니다. 이 부분도 Claude Code에게 "보안 규칙을 지금 상태 그대로 설명해 주고, 로그인한 사람만 쓰도록 바꾸려면 뭘 해야 하는지 알려 줘"라고 물어보세요.

Claude 밖으로 꺼내면 Claude 안에서만 되는 AI 부르기 · 저장 기능은 멈춥니다. 계산 · 체크리스트 · 필터는 그대로 됩니다. 페이지를 고치면 다시 배포해야 반영됩니다.
