데이터 다루기 · Claude Code 입문

날짜는 제각각, 금액엔 "삼만원", 같은 고객이 두 번 들어간 엑셀을 몇 분 만에 정리하고, 추세 · 퍼널 · 채널 성과 · 재구매율까지 직접 뽑습니다. 숫자는 정답표와 대조해 검수하고, 매주 똑같아야 하는 계산은 Claude Code로 "계산하는 도구"를 만들어 굳힙니다.

오늘의 가상 상황

팀장이 엑셀 두 개를 던집니다. "주문 데이터랑 고객 명단인데, 정리해서 이번 달 매출이랑 단골 고객 좀 뽑아 줘. 정리한 김에 재구매율이랑 어느 채널이 돈이 되는지도." 열어 보니 날짜는 6/1, 6월 1일, 06.02.2024 제각각이고, 같은 고객이 김민정 · 김 민정으로 두 번 들어가 있습니다. 예전 같으면 분석가에게 넘길 일을 오늘 직접 뽑습니다.

1. 현실의 데이터는 지저분하다 — 작업 4단계

사람이 여러 명, 여러 시점에, 다른 도구로 입력하기 때문입니다. 규칙만 정해 주면 기계가 잘 맞춥니다.

흔한 지저분함은 다섯 가지입니다. 형식 제각각(6/1, 6월 1일), 단위 · 표기 혼용(19000, ₩19000, 삼만원), 빈칸, 중복, 오타 · 띄어쓰기(데일리텀블러, 데일리 텀불러). "알아서 깔끔하게"보다 "날짜는 YYYY-MM-DD로, 금액은 숫자만"처럼 구체적으로 시키세요.

단계시킬 말
① 살펴보기"어떤 문제(빈칸 · 중복 · 형식)가 있는지 먼저 점검해 줘. 아직 고치지 마."
② 정제"날짜는 YYYY-MM-DD로, 금액은 숫자만, 상품명 오타 통일해 줘."
③ 분석 · 집계"고객별 총 구매액, 상품별 판매량을 표로."
④ 시각화 · 요약"매출 추이를 설명하고 차트로 그려 줘."

②를 건너뛰고 ③으로 가면 계산은 맞아도 답이 틀립니다. 지저분한 데이터를 넣으면 지저분한 답이 나옵니다.

데이터 파일은 대화에 첨부

Project 자료에 올린 파일은 글자만 뽑아 읽어서 시트 구조와 정확한 계산이 무너집니다. 엑셀은 대화에 직접 첨부해야 실제로 열어서 모든 시트를 읽고 계산합니다. 오늘 파일은 전부 시트가 여러 장이고, 첫 시트만 보면 틀리게 설계돼 있습니다.

2. 정제 — 지우나, 남기나, 표시하나

정제는 형식 맞추기가 아니라 행마다 내리는 판단입니다.

상황하면 안 되는 것해야 하는 것
빈칸0이나 평균으로 채우기[결측]으로 표시하고 그대로. 집계할 땐 분모에서도 빼기
중복 의심자동으로 합치기의심 표시 + 근거. 합치는 건 사람이
이상한 값조용히 고치거나 지우기표시하고 왜 이상한지 남기기

관통하는 원칙은 하나, "모르는 건 모른다고 남긴다"입니다. 이걸 안 시키면 AI는 아는 척하는 쪽을 고릅니다. 그리고 여러분은 뭐가 바뀌었는지 모르게 됩니다. 그래서 정제를 시킬 땐 항상 한 줄 더 붙입니다. "네가 값을 바꾼 행은 원래 값과 바꾼 값을 나란히 대조표로 보여 줘."

실습 A — 주문 데이터 정제

그린컵 Project에서 새 대화를 열고 messy_orders.xlsx를 첨부합니다. 시트는 주문데이터_원본(60행) · 상품마스터(정식 상품명 · 정가) · 입력규칙_안내 세 장입니다.

  1. 시트 구조부터 — "이 파일에 시트가 몇 개고 각각 뭐가 들어 있는지 먼저 알려 줘. 아직 정리하지 마." "시트가 하나뿐"이라고 답하면 파일을 제대로 못 읽은 겁니다
  2. 문제 진단 — "정리하기 전에 어떤 문제들이 있는지 목록으로 짚어 줘. 아직 고치지는 마." 심어 둔 문제 8종 · 날짜 형식 5종 + 빈칸 / 금액 표기 혼용(삼만원 · 5.7만 · ₩) / 수량에 '두개' · 빈칸 · 0 / 상품명 오타 6종 / 결제수단 4종 표기 / 주문번호만 다르고 나머지가 같은 1쌍(ORD-0603-01 · 04) / 주문번호는 같은데 금액이 다른 1쌍(ORD-0614-03) / 마이너스 금액(ORD-0608-01, 환불)
  3. 좁혀서 다시 묻기 — 한 번에 다 못 잡는 게 정상입니다.
    놓치기 쉬운 셋
    주문번호를 빼고 나머지 열이 모두 같은 행을 찾아 줘. 아직 고치지는 마.
금액이 음수인 행이 있어? 있다면 왜 그런지 메모까지 같이 보여 줘.
단가 × 수량과 금액이 맞지 않는 행을 전부 찾아, 메모에 사유가 적혀 있는지와 함께 표로 보여 줘. 아직 고치지는 마.
    주문번호는 적을 때마다 새로 붙어서 중복을 오히려 감춥니다. 그래서 비교에서 뺍니다
  4. 규칙 시트대로 정리 — "입력규칙_안내 시트를 먼저 읽고, 그 규칙대로 정리해 줘. 상품명은 상품마스터의 '정식 상품명'으로 통일해. 판단이 애매한 행은 고치지 말고 [확인필요]로 표시하고 왜 애매한지 한 줄로 적어 줘."
  5. 사람이 정할 행 받기 → 결정 → 반영 — "네가 [확인필요]로 남긴 행만 모아 보여 줘. 각 행마다 내가 뭘 결정해야 하는지도." 실행 예 9건 안팎. 개수는 AI가 묶는 방식에 따라 조금 달라집니다
  6. 변경 대조표 — "네가 값을 바꾼 행을 원래 값과 바꾼 값을 나란히 대조표로 보여 줘."
ORD-0603-02가 실습 A의 핵심입니다

"삼만원" → 30,000으로 바꾸는 건 쉽습니다. 그런데 상품마스터를 보면 접이식 실리콘컵은 17,000원입니다. 30,000원이 될 수 없고, 메모에도 "가격확인필요"라고 적혀 있습니다. 형식만 고치고 값이 애초에 가능한지는 안 보는 것, 이게 정제의 가장 흔한 사고입니다. 반대로 ORD-0605-03(26,100원)은 단가와 안 맞지만 메모에 "10% 쿠폰"이 있어 정상 거래입니다. 사유가 없을 때만 사람이 봅니다.

실습 B — 고객 명단, 합치면 안 되는 사람

같은 대화에 customer_list_messy.xlsx(42명)를 첨부합니다.

같은 사람 의심 묶기
같은 고객으로 의심되는 항목을 묶어서 보여 줘. (이름 띄어쓰기·전화번호 형식·이메일 대소문자 차이를 고려)
단, 확실하지 않으면 합치지 말고 '의심' 표시와 근거만 적어 줘.
대상판정근거
C0001 김민정 / C0002 김 민정 외 3쌍동일인 유력전화 · 이메일이 형식 · 대소문자만 다름, 생년월일 같음
C0006 최영 / C0007 최 영판단 불가 — 합치면 안 됨전화 끝자리가 다르고 C0006은 대조할 이메일 · 생년월일이 없음
C0001 김민정 / C0016 김민정다른 사람이름만 같고 전화 · 이메일 · 생년월일 전부 다름

"중복 제거해 줘"라고만 하면 이름이 같은 C0001과 C0016을 합쳐 버릴 수 있습니다. 실무에서 이러면 남의 구매 이력이 내 계정에 붙습니다. 또 동일인인 C0008 · C0040은 마케팅 수신동의가 1 vs Y로 다릅니다. 법적 근거가 필요한 항목이라 어느 값을 남길지는 AI가 아니라 사내 규칙으로 정합니다.

정제 마스터 프롬프트 — 다음 달 새 원본이 오면 이걸 먼저
첨부 파일을 정리해 줘. 순서대로.
0) 먼저 시트 구성을 알려 주고, 규칙·기준이 적힌 시트가 있으면 그걸 읽고 시작해.
1) 정리 전에 문제 목록부터: 형식 불일치 / 빈칸 / 중복 / 오타 / 값이 이상한 행
2) 정리 규칙: 날짜는 YYYY-MM-DD, 금액·수량은 숫자만, 명칭은 마스터 시트의 정식 표기, 앞뒤 공백 제거, 이메일은 소문자, 연락처는 010-1234-5678
3) 손대지 말 것
 - 빈칸은 채우지 마. [결측]으로 표시만.
 - 비슷한 항목을 임의로 합치지 마. [중복의심]과 근거만.
 - 이상한 값을 고치지 마. [확인필요]와 이유만.
4) 값의 타당성: 단가×수량과 금액이 안 맞는 행을 따로 뽑아 줘.
5) 마지막에 변경 이력표(행 | 컬럼 | 원래 값 | 바꾼 값 | 이유)와 사람이 결정할 행 목록을 붙여 줘.

3번 블록이 핵심입니다. 하라는 것보다 하지 말라는 것이 더 깁니다. 데이터 사고는 안 한 것 때문이 아니라 AI가 알아서 해 버린 것 때문에 납니다. 매달 쓸 규칙은 Project 지침에 "'월간 정제 돌려 줘'라고 하면 위 규칙으로 0~5번 순서대로 정리할 것" 한 줄로 저장해 두세요.

3. 방문자 · 매출 분석 기법

분석가가 SQL과 통계로 하던 일입니다. 기법 이름만 알면 한 문장으로 시키고, 결과도 검수할 수 있습니다.

실습 C — 90일 매출 · 방문 분석

새 대화에 sales_90days.xlsx를 첨부합니다. 시트는 일별지표 · 채널별일별 · 이벤트로그 · 지표정의 네 장입니다.

  1. 결측부터 — "일별지표에서 값이 비어 있는 날이 있는지, 이벤트로그에 그 이유가 있는지 찾아 줘. 평균·합계를 낼 때 0으로 채우는 것과 제외하는 것의 차이도 설명해." 정답 · 결측 2일(5/12, 6/9, 집계 서버 오류). 0으로 채우면 평균이 약 2% 낮게 나옵니다. 88일 기준으로 진행
  2. 추세 — "7일 이동평균을 붙이고, 월별 매출·주문수와 MoM 증감률을 표로. 결측일은 제외하고 표시해." 6월은 결측 빼면 28일이라 합계로는 +9.4%, 일평균으로는 +17.3%. 그런데 6/20 라이브 하루를 빼면 +9.3% — 성장의 절반 가까이가 이벤트 하루 덕분입니다
  3. 이상치 — "매출이 유난히 튀거나 꺼진 날을 찾아 이벤트로그와 대조해 표로. 어떤 기준으로 판단했는지도. 상관은 상관이라 쓰고, 인과는 '추정'으로 표시해." 꼭 나올 3건 · 6/20 최고 3,537,499원(라이브) · 6/21(후광 효과) · 5/18 최저 75,050원(결제 모듈 장애). 5/18은 세션 · 장바구니는 정상인데 주문만 무너졌습니다 — 퍼널로 원인을 좁히는 방법입니다
  4. 퍼널 — "세션 → 장바구니추가 → 주문수로 전환 퍼널과 단계별 전환율을 계산해 줘. 주중과 주말을 나눠서도." 세션 46,748 → 장바구니 9,890(21.2%) → 주문 4,175(42.2%), 전체 8.93%. 주말은 장바구니까지는 주중과 같고(21.1%) 결제만 떨어짐(45.3% → 31.5%) — "주말 광고 축소"가 아니라 "장바구니 이탈 리마인드"가 데이터에 맞는 액션
  5. 채널 — "채널별일별 시트로 채널별 세션·주문·매출·광고비와 전환율(주문/세션)·객단가(매출/주문)·ROAS(매출/광고비)를 표로. 광고비가 0인 채널은 ROAS '해당없음'." ROAS · 네이버검색 10.02 / 인스타그램 4.28 / 유튜브 3.10 / 직접·재방문 해당없음

표는 AI가 몇 초면 만듭니다. 하지만 "유튜브 ROAS가 꼴찌니 끄자"(6/20을 빼도 3.11로 그대로인지부터), "직접 · 재방문 전환율이 최고니 투자하자"(광고비를 넣을 수 없는 채널이고, 다른 채널이 데려온 고객이 돌아온 결과), "네이버에 몰자"(검색량 자체는 늘지 않음) 같은 판단은 우리 비즈니스를 아는 사람 몫입니다. "이 표만 보고 판단할 때 놓칠 수 있는 함정을 3가지 짚어 줘"로 AI에게 힌트를 받을 수는 있습니다.

실습 D — 재구매율의 분모 정하기

6. Claude Code — 결과가 아니라 '기계'를 받는다

Cowork는 일을 해 주고, Claude Code는 그 일을 하는 프로그램을 만들어 줍니다.

Cowork (03차시)Claude Code

7. 규칙 파일과 첫 도구

처음 한 번이 맞으면, 다음 주부터는 새 파일 넣고 같은 도구를 실행만 하면 됩니다.

실습 F — CLAUDE.md 만들고 주간 채널 분석 도구 만들기
  1. 폴더 준비 · 연결 — 바탕화면에 실적도구 폴더를 만들고 채널별 실적 엑셀을 복사해 넣습니다. Code 탭에서 Local · 수동을 확인하고 이 폴더를 고릅니다.
  2. 둘러보기 — "이 폴더에 뭐가 있는지 보여 주고, 엑셀의 시트 이름과 각 시트의 열 이름을 표로 정리해 줘. 아직 아무것도 고치거나 만들지 마." 엑셀을 열어 보는 명령을 실행하느라 허락을 물을 수 있습니다. 한 줄 설명을 읽고 허락하세요. 채널별_이번주 시트에 열 5개(유입채널 · 방문자수 · 주문건수 · 매출비중 · 전주 매출비중)가 나오면 성공
  3. CLAUDE.md 만들기
    규칙 파일
    이 폴더에 CLAUDE.md를 만들어 줘. 내용:
① 이 폴더는 그린컵 마케팅팀 주간 채널 실적 폴더다
② 원본 엑셀은 절대 고치지 않는다
③ 결과 파일은 결과/ 폴더에 저장한다
④ 나는 비개발자이니 명령을 실행하기 전에 무엇을 하는지 한 줄로 설명한다
⑤ 비율은 소수점 첫째 자리까지
⑥ 데이터가 이상하면 멈추고 나에게 묻는다
    탐색기에서 CLAUDE.md를 메모장으로 열어 여섯 줄이 다 들어갔는지 봅니다
  4. 새 대화에서 계획 받기 — Code 탭에서 새 대화를 열고 같은 폴더를 고릅니다. 규칙을 다시 말하지 않고 바로 요청합니다.
    도구 요청
    이 폴더에서 이름에 channel_performance가 들어간 엑셀 중 가장 최근 파일 하나를 읽어서,
① 매출비중 상위 3개 채널을 뽑고 ② 전주 매출비중보다 3%p 이상 변한 채널을 표시해
결과/채널집계.csv로 저장하는 도구를 만들어 줘. 만들기 전에 계획을 먼저 보여 줘.
    확인할 것 · 말 안 한 "원본은 고치지 않음", "결과/ 폴더에 저장"이 계획에 나오면 CLAUDE.md가 자동으로 읽힌 겁니다
  5. 만들고 실행 — 허락 요청마다 한 줄 설명을 읽고 허락합니다. 끝나면 도구 파일과 결과/채널집계.csv가 생겼는지 봅니다. Python이 없는 PC면 .ps1 같은 파일로 만듭니다. 정상입니다
  6. 원본과 대조 — "방금 도구가 뽑은 결과가 맞는지, 도구를 쓰지 말고 엑셀 원본 숫자로 직접 다시 확인해서 대조표로 보여 줘." 엑셀을 직접 열어 매출비중이 큰 3개도 찾아보세요. 6줄뿐이라 1분이면 됩니다.

조절 구간 — 빠른 수강생은 같은 폴더에 "다음 주" 파일을 하나 더 넣었다고 치고(엑셀 복사 후 숫자 몇 개 수정), 새 대화에서 "지난번 만든 도구로 가장 최근 파일을 다시 돌려 줘"만 시켜 보기. 같은 방식으로 계산되는지 봅니다.
